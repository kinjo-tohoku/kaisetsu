# はじめに — kaisetsu で Rietveld 解析をする

## 1. 準備

Windows ならインストーラを入れてスタートメニューから起動する([インストール](install.md))。
ソースから動かすときは:

```powershell
git clone https://github.com/kinjo-tohoku/kaisetsu
cd kaisetsu
uv sync --extra gui
uv run kaisetsu-gui
```

GUI を使わずスクリプトで動かすこともできます(`examples/refine_pbso4.py` 参照)。

## 2. 用意するもの

| もの | 形式 | 例 |
|---|---|---|
| 粉末回折データ | テキスト 2〜3 列(.xy/.xye/.txt/.csv: 2θ, 強度[, σ]。先頭のヘッダ行は無視)、Rigaku .ras/.rasx、PANalytical .xrdml、Bruker .raw(RAW1.01 ほか)、GSAS 形式(.gsa, .fxye, .raw 等。ISIS の ALT も可)、RIETAN-FP の .int(GENERAL / IGOR / 「点数 開始角 刻み」)、FullProf の .dat(自由形式、D1A/D2B の組形式)、Z-Rietveld の .histogramIgor | `data/public/fap/FAP.XRA` |
| 結晶構造 | CIF(格子定数、空間群、原子座標) | `data/public/fap/fluorapatite_COD9001232.cif` |
| 装置の情報 | ターゲット(Cu など)または波長、光学系(反射か透過か)、だいたいのピーク幅 | プリセットから選べる |

CIF の入手先: COD(crystallography.net、無料)、ICSD(研究室で契約があれば)、Materials Project、
論文の補足資料。VESTA で開いて書き出した CIF も読めます。空間群(記号か対称操作)・格子定数・原子座標が
入っていれば十分です。COD の CIF は元素記号の列が無いものや `La0` のような表記のものもありますが、
そのまま読めます。Bruker の .brml は未対応なので、装置ソフトで .raw か xy/txt に書き出してください。

### まず試せるサンプルデータ

`data/public/` に練習用の公開データと CIF を入れてあります(出典は同フォルダの README.md)。
ウィザードでデータと CIF を選ぶだけで動きます。

| フォルダ | 試料・装置 | 選ぶ装置プリセット | 目安 |
|---|---|---|---|
| `fap/` | 蛍石燐灰石、実験室 Cu Kα(Bragg-Brentano) | 実験室 X 線 Cu Kα(モノクロメータ) | 最初に試す。Rwp 8〜9% |
| `lab6/` | LaB6、Bruker D8 .raw、Cu Kα | 実験室 X 線 Cu Kα(Ni フィルタ)、半径 250 mm | 「表面粗さ」を付けると Rwp 4% |
| `garnet/` | Y3(Fe,Al)5O12、D1A 中性子 1.909 Å | 中性子、波長 1.909、Debye-Scherrer | 混合サイトの占有率も動かす。Rwp 4%、約 2 分 |
| `nac/` | NAC + CaF2、放射光 11-BM 0.4139 Å | その他、波長 0.413909、偏光 0.99、Debye-Scherrer | 2 相。点数が多いので時間がかかる |
| `pbso4/` | PbSO4、Cu Kα と D1A 中性子 | 実験室 X 線 Cu Kα(モノクロメータ)/ 中性子 | GSAS-II との比較に使ったデータ |

### Cu Kα など放射線の指定

「装置と試料の設定」ダイアログ(ツールバーの「装置設定」、Ctrl+I、データ読込時にも自動で開く)の
「放射線」欄で、**ターゲット**(Cu / Co / Cr / Fe / Mo / Ag)を選ぶと Kα1・Kα2 の波長が入ります。
放射光や中性子は「その他」にして波長を直接入れます。GSAS-II の .instprm や GSAS の .prm / .inst(APS 11-BM、NIST BT-1 などが配っている装置ファイル)があれば「装置ファイルを読む…」で波長・ピーク幅・非対称・偏光を取り込めます。Z-Rietveld の .zDiffractometer も読めます(波長・ゼロ点・U, V, W, X, Y。非対称は既定値)。.ras/.rasx/.xrdml ならファイル内の
ターゲットと波長を読んで自動で設定します。偏光係数 P は、Ni フィルタなら 0.5、回折側グラファイト
モノクロメータなら 0.56(Cu)、放射光なら 0.98〜1.0 が目安です。

## 3. ウィザードで最初の精密化

メニュー「データ → はじめての精密化(ウィザード)」を開き、

1. 回折データのファイルを選ぶ(点数と 2θ 範囲が表示される)
2. CIF を選ぶ(空間群と格子定数が表示される)
3. 装置のプリセットを選ぶ(Cu Kα の Bragg-Brentano、放射光、中性子など)。波長が違えば直す
4. 「完了」を押す

すると標準の手順で精密化が走り、ログに各段階の Rwp と χ² が出ます。

```
[スケールと背景]     変数 7   Rwp = 40.3%  χ² = 66.5
[格子定数とピーク位置] 変数 11  Rwp = 24.7%  χ² = 25.1
[ピーク幅 W]         変数 12  Rwp = 16.8%  χ² = 11.6
[ピーク幅 U, V, X, Y] 変数 16  Rwp = 12.6%  χ² = 6.5
[原子座標]           変数 27  Rwp = 12.4%  χ² = 6.3
[変位パラメータ]     変数 32  Rwp = 9.9%   χ² = 4.0
```

## 4. 画面の見方

- **図**: 黒 + が観測、赤線が計算、青線が差(観測 − 計算、下にずらして表示)、緑の縦線が各相の
  Bragg 反射位置。マウスを動かすと 2θ と d 値、観測・計算強度が左上に出ます。ホイールで拡大、
  右ドラッグで範囲指定。
- **パラメータ表**(右): すべてのパラメータの名前・値・精密化するかどうか・esd。
  赤字が現在精密化中、灰色は対称性で固定されているか他のパラメータに拘束されているもの。
  値は直接書き換えられます(書き換えたら F5 で再計算)。
- **絞り込み**: 名前の一部や glob(`*:cell:*`、`h0:inst:*`、`Pb`)で表示を絞れます。
  「表示中の項目に全部チェック / 表示中のチェックを全部外す」で、絞り込んだ分をまとめてオン・オフ。
- **ログ**(下): 読み込み、精密化の経過(反復ごとの χ²)、警告(強く相関するパラメータなど)。
- **ステータスバー**: 左に現在のヒストグラムの Rp, Rwp, Rexp, χ²。精密化中は右に
  「精密化中: 反復 n  χ² = …」と動くバーが出て、図の赤線(計算)も反復ごとに更新されます。
- **ツールバー**: ウィザード、データ読込、CIF 追加、装置設定、計算、精密化、標準の手順、中止、保存。

## 5. 手で精密化する

1. パラメータ表で動かしたいものにチェックを入れる
2. F9(精密化 → 精密化を実行)
3. 収束したらログと表の esd を確認する。Esc で途中停止できます

推奨する順序は、スケールと背景 → 格子定数とゼロ点(または試料高さずれ)→ ピーク幅(W → U, V → X, Y)
→ 原子座標 → 変位パラメータ(U_iso)→ 必要なら占有率・選択配向・非対称、です。
一度にたくさん動かすと発散しやすいので、少しずつ増やします。

### 2 相以上の精密化(混合物、不純物相)

1. ウィザードで主相の CIF を読んで 1 回精密化する(または「データ読込」→「CIF 追加」)。
2. ツールバーの「CIF 追加」で 2 つ目以降の相を加える。相ごとにスケール因子 `h0:相:scale` ができる
   (初期値 1)。少量相はまず F5 で計算して高さを見て、スケールを手で小さくしてから動かすと安定する。
3. 「標準の手順」で対象の相を「すべての相」にして実行する。
4. 「結果の要約」に相ごとの R_Bragg と重量分率(wt%)が出る。重量分率は Hill & Howard (1987) の式
   W_p = S_p M_p / Σ S_j M_j(M は単位胞の質量)で、± はスケール因子の esd から求めた値。

少量相の R_Bragg が大きいのは普通(強度が弱く背景と区別しにくい)。重量分率が数 % 以下なら
数値の信頼性は低い。選択配向があったり、重い相と軽い相の混合で微小吸収(Brindley 補正、未実装)が
効くと、分率は系統的にずれる。サンプルの `data/public/nac/`(NAC + CaF2)で試せる。

### 除外領域とデータ範囲

試料ホルダのピークや未同定の不純物ピークなど、フィットに使いたくない範囲は除外できます。

- 図の上で **Shift を押しながらドラッグ** すると、その範囲が赤い帯(除外領域)になります。
  帯はドラッグで動かせ、端をつまむと幅を変えられ、右クリックで解除できます。
- 数値で指定したいときは「データ(&D)」→「データ範囲と除外領域…」(Ctrl+E)。
  フィットに使う 2θ(TOF)の範囲もここで変えられます(範囲外は灰色で示されます)。

除外した点は精密化にも R 因子にも使われません(差のプロットも描かれません)。
除外領域はプロジェクトファイルに保存されます。

## 6. 結果の読み方

- **Rwp** が小さいほど良いが、データの統計(Rexp)で決まる下限があります。χ² = (Rwp/Rexp)² が
  1 に近づけば、残差はほぼノイズです。実験室 X 線では χ² が 2〜5 でも構造としては十分なことが多い。
- **R_Bragg / R_F**(「精密化 → 結果の要約」)は構造モデルの良さの指標で、背景やプロファイルの影響を
  受けにくい。数 % なら良好です。
- **esd**(標準偏差)は統計的な不確かさの目安。相関の強いパラメータ(U, V, W や ゼロ点と試料変位など)
  は個々の値の意味が薄いことがあります。ログに警告が出ます。
- 差のプロットにピーク形の残差が残れば、幅や非対称、選択配向(板状・針状の試料)を疑います。
  位置がずれていれば格子定数・ゼロ点・試料高さ。

## 7. 保存と出力

- 「ファイル → プロジェクトを保存」で `.kaisetsu.json` に全情報(データ、モデル、パラメータ、ログ)を保存。
- 「計算パターンを CSV に」「反射リストを CSV に」「相を CIF に」で他のソフト(Excel、VESTA 等)へ。
  PDF を表示しているときは「計算パターンを CSV に」が G(r) の書き出しになります。
- 「図を画像で保存 (PNG/SVG)」で表示中の図を保存。SVG は Illustrator や Inkscape で編集できます。
- 「表示」メニューで「構造」(相の 3D 表示。ドラッグで回転、ホイールで拡大)と「χ² の推移」
  (精密化の反復ごとの χ²。段階の区切りに縦線)のパネルを出し入れできます。

## 7a. 相の設定(Le Bail / Pawley、選択配向の軸、異方性)

「データ → 相の設定」で相ごとに次を変えられます。

- **反射強度の扱い**: 「構造モデル」(通常の Rietveld)、「Le Bail」、「Pawley」。
  Le Bail / Pawley は構造を使わず各反射の強度を観測に合わせるので、格子定数とプロファイルを先に
  決めたいとき、構造が分からないとき、MEM の入力(|F_obs|)を作るときに使います。
  Pawley は強度を最小二乗で解くので σ と重なりの相関が出ます(反射数が多いと遅い)。
- **選択配向の軸 (hkl)**: March-Dollase の配向軸。板状結晶なら劈開面の法線(雲母なら 001)、
  針状なら伸びる方向。r は `h0:相:md_r` で動かします(r < 1 で板状、r > 1 で針状が典型)。
- **異方性変位パラメータ**: チェックしたサイトを U11〜U23 にします。放射光や中性子の良いデータで、
  等方性で差のプロットにピーク形の残差が残るときに。実験室 X 線では普通は等方性で十分です。
- **Brindley 微小吸収補正の粒子半径**: 重い相と軽い相の混合で重量分率が系統的にずれるときに、
  粒子半径(μm)を入れると補正します(X 線のみ)。
- **歪み広がりを異方的にする(Stephens)**: hkl の方向でピーク幅が違う(ある指数の反射だけ太い)ときに。
  係数 `h0:相:S_HKL` がラウエ群に応じた数だけ自由になり(立方晶 2、正方晶 4、斜方晶 6 …)、
  等方的な `strain` の値から初期化されます。
- **結晶子サイズを一軸異方的にする**: 板状(ある面の反射だけ太い)や針状の結晶に。軸 (hkl) は板の法線または
  針の方向。軸方向のサイズが `h0:相:size_ax`、軸に垂直な方向が `h0:相:size` になります
  (板状なら size_ax < size、針状なら size_ax > size)。
- **球面調和関数の集合組織を使う**: March-Dollase(1 軸・1 パラメータ)で選択配向が取り切れないときに。
  最大次数 L(偶数、4 が目安)を選ぶと、ラウエ群で許される調和関数の係数 `h0:相:sh2_1`、`sh4_1`、…が
  0(無配向)から始まります。併用するときは `md_r` を 1 に固定してください。要約に出る集合組織指数 J は
  1 が無配向で、大きいほど強い配向です。平板試料(Bragg-Brentano)と毛細管(Debye-Scherrer)のどちらでも
  使えます(試料の向きの因子は係数に吸収されます)。

## 7b. PDF(二体分布関数)解析

G(r) のファイル(PDFgetX2/X3、PDFgetN、xPDFsuite の .gr、または r, G の 2 列テキスト)があれば、

1. CIF から相を追加する(粉末データは無くてもよい)。
2. 「データ → PDF データ G(r) を読み込む」。放射線、Q_max(ヘッダにあれば自動)、
   Q_damp の初期値(放射光 X 線 0.03〜0.07、中性子 0.01〜0.03)、フィット範囲(r = 1.5〜20 Å が目安)を入れる。
3. 「精密化 → PDF の標準手順で精密化」。スケール → 格子定数 → U と δ2 → Q_damp → 原子座標 → 最終、の順です。
4. 「結果の要約」に Rw と χ² が出ます。Rw は 5〜15% が目安(PDF は Rwp より大きめに出ます)。

まず試すなら `data/public/pdf/` の Ni(`Ni-xray.gr`、`Ni.cif`)。Rw ≈ 7%、a ≈ 3.532 Å になります。

パラメータ: `g0:pdf:scale|qdamp|qbroad`(データセット)、`g0:相:scale|delta1|delta2|sratio|spdiameter`(相)。
δ2(Å²)は近距離のピークを鋭くする相関運動補正で、室温付近では 2〜3 程度。δ1 は高温用で普通は 0 のまま。
spdiameter はナノ粒子の直径(Å)で、バルクなら 0。

I(Q)(または 2θ の全散乱データ)しか無いときは「データ → I(Q) から G(r) を作る」で、組成式・Q 範囲・
容器の差し引きを入れて変換し(PDFgetX3 と同じアドホック多項式補正)、プレビューを見てから追加できます。
粉末データと PDF を同時に持てば、同じ構造モデルで両方を一度に精密化します(残差を連結)。

## 7c. MEM 電子密度・核密度と MPF

Rietveld 精密化のあと「精密化 → MEM 電子密度 / 核密度」。

1. ヒストグラムと相を選ぶ。観測 |F| は Rietveld 分配(位相は構造モデル)か、相を Pawley にしてあれば
   Pawley の強度(σ と相関込み)から作ります。
2. 格子点の間隔(既定 0.1 Å。細かいほど滑らかだが時間がかかる)。中性子で負の散乱長(Ti, Mn, H など)が
   あるときは「2 チャンネル」にチェック。
3. 「MEM を実行」。C(= χ²)が 1 になるまで数十秒〜数分。断面(a/b/c 軸に垂直)をスライダーで眺め、
   極大の位置と値を確認します。
4. CCP4 / XPLOR / VESTA grd に書き出せば VESTA で等値面や断面を描けます(相の CIF も一緒に書き出す)。
5. MPF のサイクル数を 1 以上にすると、MEM の |F| で重なった反射を分け直し、パターンフィッティングと
   MEM を往復します(Rwp が Rietveld 単独より少し下がれば収束)。

試すなら PbSO4(`examples/mem_pbso4.py` と同じ): Pb の位置に 700 e/Å³ 程度の最大、S、O の順に極大が出ます。

## 7f. TOF 中性子(J-PARC、SNS、ISIS)

飛行時間データ(GSAS 形式の .gsa / .fxye で、BANK 行が SLOG など CONST 以外のもの)を読み込むと、
TOF 装置パラメータのダイアログが開きます。装置から受け取った GSAS-II の .instprm があれば
「装置ファイルを読む」で入れます(無ければ DIFC と 2θ をヘッダから推定した値が入ります)。
Z-Rietveld の .zDiffractometer(J-PARC の iMATERIA、SuperHRPD など)からは換算係数 c₀, c₁, c₂、
バンク角、Type0m / Type0 のガウス分散 σ²(SigmaSquare0〜2)とローレンツ幅 γ(Gamma0〜2)を
取り込みます。立ち上がり α と減衰 β は Z-Rietveld と関数形が違う(Ikeda-Carpenter 系)ので
取り込まず、標準の手続きがデータから求めます。
パラメータ名は `h0:inst:difc|difa|difb|zero|alpha|beta0|beta1|betaq|sig0|sig1|sig2|sigq|x|y|z`。
標準の手順はそのまま使えます(ゼロ点の代わりに `zero`、幅は `sig1`, `alpha`, `beta0`, `beta1` を
同時に動かしてから `sig0`, `sig2`, `x`, `y`)。立ち上がりが分解能より速い装置(iMATERIA など)では
α が上限 10 付近で「決まっていません」と出ますが、フィットには害がないのでそのままで構いません。
注意: Z-Rietveld の DIFC(c₁)は Ikeda-Carpenter 型の関数でピーク位置を定義して校正されているので、
本プログラムの back-to-back 指数関数で使うと格子定数が 10⁻⁴ 程度ずれます(CeO2 で 5.4120 に対し
5.4093 Å)。格子定数を精密に求めるには、標準試料(Si、CeO2)で DIFC とゼロ点を本プログラムで
精密化し直してください。
試すなら `data/public/nac/PG3_22048.gsa` と `POWGEN_1066.instprm`、相は `NAC.cif`。

- **強度の単位**: GSAS 形式の TOF データはビン幅で割って counts/μs にして扱います(GSAS-II と同じ。
  SLOG のようにビン幅が変わるデータで必要)。x はビン中心に移すので点が 1 つ減ります。
- **複数バンク**: BANK が複数あるファイルは、読み込むバンクを選ぶか「すべてのバンク」で
  バンクごとにヒストグラムを追加できます(装置ダイアログはバンクごとに出ます。同時精密化は
  パラメータ表で `h0:`, `h1:` … を一緒にチェックするだけ)。
- **吸収**: バナジウム缶の μR を λ = 1 Å での値で入れます(ダイアログの「吸収 μR」、または
  `h0:sample:mu_r`)。反射ごとに波長に比例させて補正します。吸収の強い試料(Cd, Gd, B など)で
  長い d の反射が弱く出るときに精密化してください。
- **消衰**: 結晶子が大きく(数 μm 以上)強い反射が計算より弱いときは `h0:相:ext`(Sabine の係数、
  GSAS-II の Extinction と同じ単位)を動かします。実験室 X 線では普通は 0 のままで構いません。

## 7d. 連続データ(温度・時間系列)の逐次精密化

1 つ目のデータで精密化を済ませ、動かすパラメータにチェックを入れた状態で
「データ → 連続データを順に精密化」。ファイルを複数選んで「実行」すると、前の結果を初期値にして
順に精密化し、Rwp・χ²・各パラメータ(esd 付き)の表が出ます。「CSV に保存」で表計算ソフトへ。
スクリプトでは `kaisetsu.refine.sequential.refine_sequence` が同じことをします。

## 7e. 英語表示・大きなデータの保存

- 英語のメニューにするには `uv run kaisetsu-gui --lang en`(設定 "language" を "en" にしても同じ)。
  主要なメニュー・ツールバー・パネル名だけが英語になり、説明文は日本語のままです。
- 数万点を超えるデータは、スクリプトで `save_project(proj, path, external_arrays=True)` とすると
  配列を同名の .npz に分けて保存できます(JSON が軽くなる)。読み込みは同じ `load_project`。

## 8. パラメータ名の規則

```
相:cell:a|b|c|alpha|beta|gamma      格子定数(晶系で自動的に拘束)
相:サイト:x|y|z                      分率座標(特殊位置の拘束は自動)
相:サイト:occ, uiso, u11..u23       占有率、変位パラメータ
h0:inst:zero|u|v|w|x|y|sh_l|pol         装置(h0 は 1 番目のデータ。詳細: p, z)
h0:sample:displacement|transparency|disp_x|disp_y|mu_r   試料
h0:bkg:0,1,2,…                      背景(Chebyshev 係数、固定点補間では各点の高さ)
h0:hump0:center|fwhm|height         非晶質ハンプ(中心、半値全幅、高さ)
h0:inst:kb_ratio                    Kβ 線の強度比(装置設定で「Kβ あり」のとき)
h0:相:scale|md_r|size|strain        スケール、選択配向 r、結晶子サイズ(μm)、微小歪み
g0:pdf:scale|qdamp|qbroad           PDF データセット(g0 は 1 番目の G(r))
g0:相:scale|delta1|delta2|sratio|spdiameter   相の PDF パラメータ
```

## 9. 困ったとき

- **背景が合わない(低角の立ち上がり、緩やかなうねり)**: 「データ → 背景の設定」で項数を増やす
  (既定 8、目安 6〜12)。読み込み時にピークを避けて背景を自動推定しているので、項数を変えて
  「推定し直す」にチェックを入れると初期値も作り直されます。ピークが密な高角で背景がピークの裾を
  吸い始めたら項数を減らします。
- **「ガウス幅 Γ_G² が … で負です」と注意が出る**: U, V, W の組み合わせがデータの一部で負に
  なり、その範囲はガウス成分を 0 として計算しています(GSAS-II と同じ扱い)。フィットが良ければ
  実害は小さいですが、U, V, W は装置の特性としては意味を失います。装置として意味のある値が
  欲しければ W か U を固定するか、「精密化」→「ピーク幅が負にならないよう拘束する」を有効にして
  精密化し直してください(拘束すると Rwp が悪くなることがあります。付属の PbSO4 で 9.9% → 14%)。
  標準手順は負になったら U を初期値に固定してやり直します。ローレンツ幅 Γ_L(X, Y, Z)や
  TOF の σ² も同じです。
- **発散する(Rwp が増える・値が飛ぶ)**: いったん「すべて固定」し、スケールと背景だけからやり直す。
  ピーク位置が大きくずれていれば先にゼロ点か格子定数だけを動かす。
- **ピークが細すぎる / 太すぎる**: 装置設定で W(全角に効く)を観測の FWHM² の目安に合わせる。
  Cu Kα の実験室装置なら W ≈ 0.003〜0.01 deg²。
- **強度比が合わない**: 選択配向(`h0:相:md_r`、配向軸は板状結晶の面)、占有率、U_iso の順に疑う。
- **U_iso が負になる**: 吸収の強い試料を平板に詰めたときの表面粗さ効果が典型(LaB6 のサンプルで再現できる)。
  「標準の手順」で「表面粗さを動かす」を付けるか、`h0:sample:rough_a` を動かす(1 = 補正なし、小さいほど粗い。b は 1 に固定)。
  背景が高すぎる・偏光係数が合っていないときにも起こる。精密化のあとに出る「注意:」のログも参考にする。
- **占有率を動かすと esd が巨大になる**: 占有率 1 で混合でもないサイトの占有率はスケール因子と区別
  できない。「標準の手順」の占有率は混合サイトと部分占有サイトだけを動かす。混合サイトは占有率の和が
  自動で保たれる(後に書かれた種が従属)。
- **CIF が読めない**: 空間群の記号か対称操作が必要です。VESTA 等で書き出し直すと読めることが多い。

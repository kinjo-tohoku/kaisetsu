# はじめに — kaisetsu で Rietveld 解析をする

この説明書はアプリの中からも読めます(ヘルプ → 「利用者ガイド」、または F1)。

## 1. 準備

Windows ならインストーラを入れてスタートメニューから起動する([インストール](install.md))。
ソースから動かすときは:

```powershell
git clone https://github.com/kinjo-tohoku/kaisetsu
cd kaisetsu
uv sync --extra gui
uv run kaisetsu-gui
```

GUI を使わずスクリプトで動かすこともできます(`examples/refine_pbso4.py` 参照)。

## 2. 用意するもの

| もの | 形式 | 例 |
|---|---|---|
| 粉末回折データ | テキスト 2〜3 列(.xy/.xye/.txt/.csv: 2θ, 強度[, σ]。先頭のヘッダ行は無視)、Rigaku .ras/.rasx、PANalytical .xrdml、Bruker .raw(RAW1.01 ほか)、GSAS 形式(.gsa, .fxye, .raw 等。ISIS の ALT も可)、RIETAN-FP の .int(GENERAL / IGOR / 「点数 開始角 刻み」)、FullProf の .dat(自由形式、D1A/D2B の組形式)、Z-Rietveld の .histogramIgor、pdCIF(COD や Acta Cryst. E の CIF に粉末データが入っているもの。同じ CIF を相にも使える) | `data/public/fap/FAP.XRA` |
| 結晶構造 | CIF(格子定数、空間群、原子座標) | `data/public/fap/fluorapatite_COD9001232.cif` |
| 装置の情報 | ターゲット(Cu など)または波長、光学系(反射か透過か)、だいたいのピーク幅 | プリセットから選べる |

CIF の入手先: COD(crystallography.net、無料)、ICSD(研究室で契約があれば)、Materials Project、
論文の補足資料。VESTA で開いて書き出した CIF も読めます。空間群(記号か対称操作)・格子定数・原子座標が
入っていれば十分です。COD の CIF は元素記号の列が無いものや `La0` のような表記のものもありますが、
そのまま読めます。Bruker の .brml は未対応なので、装置ソフトで .raw か xy/txt に書き出してください。

手で打った CIF の注意: 座標は小数で書きます(`1/3` は 0.333333 と解釈して読み込みの警告に出します。
`?` のままだと止まります)。論文の表の 3 桁の座標(0.333, 0.667)でも特殊位置として扱い、1/3, 2/3 に
乗せ直します。対称操作が無く、原点選択が 2 つある空間群(Fd-3m、Pnnn、I41/amd、P4/nmm など)では、
CIF の多重度(`_atom_site_symmetry_multiplicity`)か原子間距離から原点を推定して警告に出します。
違っていたら記号に `:1` / `:2` を付けてください(ICSD の `F d -3 m S` / `Z` も読めます)。
読み込んだ多重度が CIF の多重度と合わないとき、同じラベルが 2 回あって付け直したときも警告が出ます。

### まず試せるサンプルデータ

`data/public/` に練習用の公開データと CIF を入れてあります(出典は同フォルダの README.md)。
ウィザードでデータと CIF を選ぶだけで動きます。

| フォルダ | 試料・装置 | 選ぶ装置プリセット | 目安 |
|---|---|---|---|
| `fap/` | 蛍石燐灰石、実験室 Cu Kα(Bragg-Brentano) | 実験室 X 線 Cu Kα(モノクロメータ) | 最初に試す。Rwp 8〜9% |
| `lab6/` | LaB6、Bruker D8 .raw、Cu Kα | 実験室 X 線 Cu Kα(Ni フィルタ)、半径 250 mm | 「表面粗さ」を付けると Rwp 4% |
| `garnet/` | Y3(Fe,Al)5O12、D1A 中性子 1.909 Å | 中性子、波長 1.909、Debye-Scherrer | 混合サイトの占有率も動かす。Rwp 4%、約 2 分 |
| `nac/` | NAC + CaF2、放射光 11-BM 0.4139 Å | その他、波長 0.413909、偏光 0.99、Debye-Scherrer | 2 相。点数が多いので時間がかかる |
| `pbso4/` | PbSO4、Cu Kα と D1A 中性子 | 実験室 X 線 Cu Kα(モノクロメータ)/ 中性子 | GSAS-II との比較に使ったデータ |
| `baclo4/` | Ba(ClO4)2、PANalytical Cu Kα1(pdCIF。データも相も同じ CIF) | 実験室 X 線 Cu Kα(モノクロメータ)、Kα2 なし | 非晶質のこぶを標準手順がハンプにする例。Rwp 7%(公表 6%) |

### Cu Kα など放射線の指定

「装置と試料の設定」ダイアログ(ツールバーの「装置設定」、Ctrl+I、データ読込時にも自動で開く)の
「放射線」欄で、**ターゲット**(Cu / Co / Cr / Fe / Mo / Ag)を選ぶと Kα1・Kα2 の波長が入ります。
放射光や中性子は「その他」にして波長を直接入れます。GSAS-II の .instprm や GSAS の .prm / .inst(APS 11-BM、NIST BT-1 などが配っている装置ファイル)があれば「装置ファイルを読む…」で波長・ピーク幅・非対称・偏光を取り込めます。Z-Rietveld の .zDiffractometer も読めます(波長・ゼロ点・U, V, W, X, Y。非対称は既定値)。.ras/.rasx/.xrdml ならファイル内の
ターゲットと波長を読んで自動で設定します。偏光係数 P は、Ni フィルタなら 0.5、回折側グラファイト
モノクロメータなら 0.56(Cu)、放射光なら 0.98〜1.0 が目安です。

## 3. ウィザードで最初の精密化

メニュー「データ → はじめての精密化(ウィザード)」を開き、

1. 回折データのファイルを選ぶ(点数と 2θ 範囲が表示される)
2. CIF を選ぶ(空間群と格子定数が表示される)
3. 装置のプリセットを選ぶ(Cu Kα の Bragg-Brentano、放射光、中性子など)。波長が違えば直す
4. 「解析の種類」で Rietveld か Le Bail を選ぶ。Rietveld は CIF の原子座標から強度を計算して構造まで
   精密化します。Le Bail は構造を使わず各反射の強度を観測に合わせ、格子定数とピーク形だけを決めます
   (構造が分からない、合っているか怪しい、CIF に原子座標が無い、まず格子定数だけ知りたいとき)
5. 「完了」を押す

すると標準の手順で精密化が走り、ログに各段階の Rwp と χ² が出ます。

```
[スケールと背景]     変数 7   Rwp = 40.3%  χ² = 66.5
[格子定数とピーク位置] 変数 11  Rwp = 24.7%  χ² = 25.1
[ピーク幅 W]         変数 12  Rwp = 16.8%  χ² = 11.6
[ピーク幅 U, V, X, Y] 変数 16  Rwp = 12.6%  χ² = 6.5
[原子座標]           変数 27  Rwp = 12.4%  χ² = 6.3
[変位パラメータ]     変数 32  Rwp = 9.9%   χ² = 4.0
```

最初の「格子定数の初期値を振る」は、CIF の格子定数を ±1% の範囲で細かく振って(刻みは高角端の
ピーク幅)、計算ピークが観測ピークに重なる初期値を探します。初期値が谷の外にあると最小二乗は
格子定数を正しい方向に動かせません(放射光級の鋭いピークでは 0.6% のずれで止まり、3% では発散します)。
±1% で見つからず Rwp も悪ければ ±3% に広げます。正方・六方・斜方晶では等方のあとで各軸も振ります。
数秒で済み、初期値が合っていれば何も変えません(ログに「初期値のままが最良です」と出ます)。
ピーク幅のあとに「残差のこぶを背景に試す」が入り、残差に幅の広い山(ガラスキャピラリや非晶質成分の
こぶ)が残っていれば背景にガウスのハンプを足して精密化し、Rwp が 0.5 ポイント以上良ければ採用します
(ログに中心と幅が出ます)。続く「Kα2 なしを試す」は、Kα2 を外した方が Rwp で 0.3 ポイント以上良ければ
採用します(単色化されたデータ。放射光や中性子では何もしません)。放射光(λ < 1.2 Å)では
非対称 SH/L も動かします。重原子が散乱を支配する相(例: PbSO4 の O)では「変位パラメータ」の
段階で軽原子(O, C, Li など)の U_iso を共通の 1 つにします(個別には決まらないため。ログに出ます)。
「Le Bail も走らせる」を付けておくと、最後に構造を使わない Le Bail の Rwp(プロファイルと背景だけの
下限)が出ます。Rietveld との差が大きければ構造モデル(占有率・選択配向・第二相)を疑う目安です。
「解析の種類」を Le Bail にしたときは、相が「Le Bail 法」に切り替わり(相の一覧に「Le Bail」と付く)、
原子座標と変位パラメータの段階は飛ばして、各段階で反射の強度を観測に合わせ直しながら格子定数と
ピーク幅を精密化します(R_Bragg や構造の量は出ません)。そのあと Rietveld に進むには
「データ → 相の設定」で「構造モデルから計算(Rietveld)」に戻し、「標準の手順」を走らせます
(格子定数とピーク幅は決めた値から始まります)。
精密化のあとの「注意:」には、相の反射で説明できないピークやこぶの候補も出ます
(「精密化 → 残差の点検」で除外領域やハンプにできます)。

## 4. 画面の見方

- **図**: 黒 + が観測、赤線が計算、青線が差(観測 − 計算、下にずらして表示)、緑の縦線が各相の
  Bragg 反射位置。マウスを動かすと 2θ と d 値、観測・計算強度が左上に出ます。ピークの上に
  カーソルを置くと 2 行目に近い反射の hkl、d 値、相対強度(相の最強反射を 100 とした計算強度)が
  出ます(相が 2 つ以上なら相名付き。重なっていれば近い順に最大 4 本)。強度の合わないピークが
  00l や h00 ばかりなら選択配向、どの相の反射でもなければ第二相の目安になります。
  ホイールで拡大、右ドラッグで範囲指定。
- **パラメータ表**(右): すべてのパラメータの名前・値・精密化するかどうか・esd。
  赤字が現在精密化中、灰色は対称性で固定されているか他のパラメータに拘束されているもの。
  値は直接書き換えられます(書き換えたら F5 で再計算)。
- **絞り込み**: 名前の一部や glob(`*:cell:*`、`h0:inst:*`、`Pb`)で表示を絞れます。
  「表示中の項目に全部チェック / 表示中のチェックを全部外す」で、絞り込んだ分をまとめてオン・オフ。
- **パネルの幅**: パラメータ表と図の境目をドラッグすると幅を変えられます(ノート PC では 300 px
  程度まで狭くできます。絞り込みのボタンは折り返します)。見出しをドラッグすると切り離して別の窓に
  できます。「表示」メニューで隠すこともできます。窓の大きさとパネルの配置は次回の起動に引き継がれます。
- **ログ**(下): 読み込み、精密化の経過(反復ごとの χ²)、警告(強く相関するパラメータなど)。
- **ステータスバー**: 左に現在のヒストグラムの Rp, Rwp, Rexp, χ²。精密化中は右に
  「精密化中: 反復 n  χ² = …」と動くバーが出て、図の赤線(計算)も反復ごとに更新されます。
- **ツールバー**: ウィザード、データ読込、CIF 追加、装置設定、計算、精密化、標準の手順、中止、保存。

## 5. 手で精密化する

1. パラメータ表で動かしたいものにチェックを入れる
2. F9(精密化 → 精密化を実行)
3. 収束したらログと表の esd を確認する。Esc で途中停止できます
4. 結果が気に入らなければ Ctrl+Z(精密化 → 直前の精密化の前に戻す)で精密化前の値に戻せます
   (もう一度押すと戻す前の値に戻ります)。「すべて初期値に戻す」はデータ・CIF を読み込んだとき
   (装置や背景を設定し直したときはその値)に戻します。パラメータ表の「表示中の値を初期値に戻す」
   で、絞り込んだ量だけ戻すこともできます

推奨する順序は、スケールと背景 → 格子定数とゼロ点(または試料高さずれ)→ ピーク幅(W → U, V → X, Y)
→ 原子座標 → 変位パラメータ(U_iso)→ 必要なら占有率・選択配向・非対称、です。
「標準の手順」はこの順に加えて Kα2 なしの試行と軽原子 U_iso の共通化を自動で行います
(ダイアログのチェックで外せます)。
一度にたくさん動かすと発散しやすいので、少しずつ増やします。

### 2 相以上の精密化(混合物、不純物相)

1. ウィザードで主相の CIF を読んで 1 回精密化する(または「データ読込」→「CIF 追加」)。
2. ツールバーの「CIF 追加」で 2 つ目以降の相を加える。相ごとにスケール因子 `h0:相:scale` ができる
   (初期値 1)。少量相はまず F5 で計算して高さを見て、スケールを手で小さくしてから動かすと安定する。
3. 「標準の手順」で対象の相を「すべての相」にして実行する。
4. 「結果の要約」に相ごとの R_Bragg と重量分率(wt%)が出る。重量分率は Hill & Howard (1987) の式
   W_p = S_p M_p / Σ S_j M_j(M は単位胞の質量)で、± はスケール因子の esd から求めた値。

少量相の R_Bragg が大きいのは普通(強度が弱く背景と区別しにくい)。重量分率が数 % 以下なら
数値の信頼性は低い。選択配向があったり、重い相と軽い相の混合で微小吸収(Brindley 補正、未実装)が
効くと、分率は系統的にずれる。サンプルの `data/public/nac/`(NAC + CaF2)で試せる。

### 除外領域とデータ範囲

試料ホルダのピークや未同定の不純物ピークなど、フィットに使いたくない範囲は除外できます。

- 図の上で **Shift を押しながらドラッグ** すると、その範囲が赤い帯(除外領域)になります。
  帯はドラッグで動かせ、端をつまむと幅を変えられ、右クリックで解除できます。
- 数値で指定したいときは「データ(&D)」→「データ範囲と除外領域…」(Ctrl+E)。
  フィットに使う 2θ(TOF)の範囲もここで変えられます(範囲外は灰色で示されます)。
  範囲を変えると、背景の多項式(Chebyshev)の定義域も新しい範囲に合わせて書き直されます
  (曲線は変わりません)。定義域が範囲より広いままだと背景の係数が決まらず、相関の注意が出ます。

除外した点は精密化にも R 因子にも使われません(差のプロットも描かれません)。
除外領域はプロジェクトファイルに保存されます。

## 6. 結果の読み方

- **Rwp** が小さいほど良いが、データの統計(Rexp)で決まる下限があります。χ² = (Rwp/Rexp)² が
  1 に近づけば、残差はほぼノイズです。実験室 X 線では χ² が 2〜5 でも構造としては十分なことが多い。
- **R_Bragg / R_F**(「精密化 → 結果の要約」)は構造モデルの良さの指標で、背景やプロファイルの影響を
  受けにくい。数 % なら良好です。
- **esd**(標準偏差)は統計的な不確かさの目安。相関の強いパラメータ(U, V, W や ゼロ点と試料変位など)
  は個々の値の意味が薄いことがあります。ログに警告が出ます。「データに感度がありません」は、
  その変数を変えても計算パターンが変わらない(ピーク幅が負の範囲で 0 に切られているなど)ので
  esd を出せない、という意味です。固定してください。「組み合わせでしか決まりません」は、
  ゼロ点と試料高さずれのように 2 つを同時に動かすと区別できない組で、どちらかを固定します。
- 差のプロットにピーク形の残差が残れば、幅や非対称、選択配向(板状・針状の試料)を疑います。
  位置がずれていれば格子定数・ゼロ点・試料高さ。

## 7. 保存と出力

- 「ファイル → プロジェクトを保存」で `.kaisetsu.json` に全情報(データ、モデル、パラメータ、ログ)を保存。
- 「計算パターンを CSV に」「反射リストを CSV に」「相を CIF に」で他のソフト(Excel、VESTA 等)へ。
  PDF を表示しているときは「計算パターンを CSV に」が G(r) の書き出しになります。
- 「図を画像で保存 (PNG/SVG)」で表示中の図を保存。SVG は Illustrator や Inkscape で編集できます。
- 「表示」メニューで「構造」(相の 3D 表示。ドラッグで回転、ホイールで拡大)と「χ² の推移」
  (精密化の反復ごとの χ²。段階の区切りに縦線)のパネルを出し入れできます。

## 7a. 相の設定(Le Bail / Pawley、選択配向の軸、異方性)

「データ → 相の設定」で相ごとに次を変えられます。

- **反射強度の扱い**: 「構造モデル」(通常の Rietveld)、「Le Bail」、「Pawley」。
  Le Bail / Pawley は構造を使わず各反射の強度を観測に合わせるので、格子定数とプロファイルを先に
  決めたいとき、構造が分からないとき、MEM の入力(|F_obs|)を作るときに使います。
  Pawley は強度を最小二乗で解くので σ と重なりの相関が出ます(反射数が多いと遅い)。
  Le Bail の入口は 3 つあります: ウィザードの「解析の種類」で Le Bail(データと CIF から一気に。3 節)、
  「データ → Le Bail で自動解析」(複数ファイルの一括処理と格子定数の表・CSV。7g 節)、ここで相を
  「Le Bail 法」にして「標準の手順」か「精密化」(読み込み済みのプロジェクトで相ごとに切り替えたいとき。
  混合物で一方だけ Le Bail、Rietveld の途中で切り替えるなど)。
- **選択配向の軸 (hkl)**: March-Dollase の配向軸。板状結晶なら劈開面の法線(雲母なら 001)、
  針状なら伸びる方向。r は `h0:相:md_r` で動かします(r < 1 で板状、r > 1 で針状が典型)。
- **異方性変位パラメータ**: チェックしたサイトを U11〜U23 にします。放射光や中性子の良いデータで、
  等方性で差のプロットにピーク形の残差が残るときに。実験室 X 線では普通は等方性で十分です。
- **Brindley 微小吸収補正の粒子半径**: 重い相と軽い相の混合で重量分率が系統的にずれるときに、
  粒子半径(μm)を入れると補正します(X 線のみ)。
- **歪み広がりを異方的にする(Stephens)**: hkl の方向でピーク幅が違う(ある指数の反射だけ太い)ときに。
  係数 `h0:相:S_HKL` がラウエ群に応じた数だけ自由になり(立方晶 2、正方晶 4、斜方晶 6 …)、
  等方的な `strain` の値から初期化されます。
- **結晶子サイズを一軸異方的にする**: 板状(ある面の反射だけ太い)や針状の結晶に。軸 (hkl) は板の法線または
  針の方向。軸方向のサイズが `h0:相:size_ax`、軸に垂直な方向が `h0:相:size` になります
  (板状なら size_ax < size、針状なら size_ax > size)。
- **球面調和関数の集合組織を使う**: March-Dollase(1 軸・1 パラメータ)で選択配向が取り切れないときに。
  最大次数 L(偶数、4 が目安)を選ぶと、ラウエ群で許される調和関数の係数 `h0:相:sh2_1`、`sh4_1`、…が
  0(無配向)から始まります。併用するときは `md_r` を 1 に固定してください。要約に出る集合組織指数 J は
  1 が無配向で、大きいほど強い配向です。平板試料(Bragg-Brentano)と毛細管(Debye-Scherrer)のどちらでも
  使えます(試料の向きの因子は係数に吸収されます)。

## 7b. PDF(二体分布関数)解析

G(r) のファイル(PDFgetX2/X3、PDFgetN、xPDFsuite の .gr、または r, G の 2 列テキスト)があれば、

1. CIF から相を追加する(粉末データは無くてもよい)。
2. 「データ → PDF データ G(r) を読み込む」。放射線、Q_max(ヘッダにあれば自動)、
   Q_damp の初期値(放射光 X 線 0.03〜0.07、中性子 0.01〜0.03)、フィット範囲(r = 1.5〜20 Å が目安)を入れる。
3. 「精密化 → PDF の標準手順で精密化」。スケール → 格子定数 → U と δ2 → Q_damp → 原子座標 → 最終、の順です。
4. 「結果の要約」に Rw と χ² が出ます。Rw は 5〜15% が目安(PDF は Rwp より大きめに出ます)。

まず試すなら `data/public/pdf/` の Ni(`Ni-xray.gr`、`Ni.cif`)。Rw ≈ 7%、a ≈ 3.532 Å になります。

パラメータ: `g0:pdf:scale|qdamp|qbroad`(データセット)、`g0:相:scale|delta1|delta2|sratio|spdiameter`(相)。
δ2(Å²)は近距離のピークを鋭くする相関運動補正で、室温付近では 2〜3 程度。δ1 は高温用で普通は 0 のまま。
spdiameter はナノ粒子の直径(Å)で、バルクなら 0。

I(Q)(または 2θ の全散乱データ)しか無いときは「データ → I(Q) から G(r) を作る」で、組成式・Q 範囲・
容器の差し引きを入れて変換し(PDFgetX3 と同じアドホック多項式補正)、プレビューを見てから追加できます。
粉末データと PDF を同時に持てば、同じ構造モデルで両方を一度に精密化します(残差を連結)。

## 7c. MEM 電子密度・核密度と MPF

Rietveld 精密化のあと「精密化 → MEM 電子密度 / 核密度」。

1. ヒストグラムと相を選ぶ。観測 |F| は Rietveld 分配(位相は構造モデル)か、相を Pawley にしてあれば
   Pawley の強度(σ と相関込み)から作ります。
2. 格子点の間隔(既定 0.1 Å。細かいほど滑らかだが時間がかかる)。中性子で負の散乱長(Ti, Mn, H など)が
   あるときは「2 チャンネル」にチェック。
3. 「MEM を実行」。C(= χ²)が 1 になるまで数十秒〜数分。断面(a/b/c 軸に垂直)をスライダーで眺め、
   極大の位置と値を確認します。
4. CCP4 / XPLOR / VESTA grd に書き出せば VESTA で等値面や断面を描けます(相の CIF も一緒に書き出す)。
5. MPF のサイクル数を 1 以上にすると、MEM の |F| で重なった反射を分け直し、パターンフィッティングと
   MEM を往復します(Rwp が Rietveld 単独より少し下がれば収束)。

試すなら PbSO4(`examples/mem_pbso4.py` と同じ): Pb の位置に 700 e/Å³ 程度の最大、S、O の順に極大が出ます。

## 7f. TOF 中性子(J-PARC、SNS、ISIS)

飛行時間データ(GSAS 形式の .gsa / .fxye で、BANK 行が SLOG など CONST 以外のもの)を読み込むと、
TOF 装置パラメータのダイアログが開きます。装置から受け取った GSAS-II の .instprm があれば
「装置ファイルを読む」で入れます(無ければ DIFC と 2θ をヘッダから推定した値が入ります)。
Z-Rietveld の .zDiffractometer(J-PARC の iMATERIA、SuperHRPD など)からは換算係数 c₀, c₁, c₂、
バンク角、プロファイル Type0m のすべて(σ²、γ、Alpha1/2、Beta1_0、Beta0_0/1、r01〜r03)を
取り込み、プロファイル関数を「Z-Rietveld Type0m」に切り替えて Z-Rietveld と同じ形で計算します
(関数形は Z-Rietveld の計算曲線から逆算したもので、ピーク形状は iMATERIA の BS 155° と SE 90° の
両バンクで 0.05% 以内、位置の定義も同じ。詳細は docs/validation/phase7_tof.md 8 節)。
iMATERIA の CeO2 では装置ファイルの値をそのまま使った標準の手順で、BS バンクが Rwp 8.1%、
格子定数 5.41223 Å(Z-Rietveld の解 5.41197〜5.41234 Å)、SE バンクが Rwp 6.2% になります。
パラメータ名は `h0:inst:difc|difa|difb|zero|sig0|sig1|sig2|sigq|x|y|z` と、GSAS type 3 なら
`alpha|beta0|beta1|betaq`、Type0m なら `zr_alpha1|zr_alpha2|zr_beta1|zr_beta0_0|zr_beta0_1|zr_r01|zr_r02|zr_r03`
(Z-Rietveld と同じく装置の定数として固定しておくのが普通です)。
標準の手順はそのまま使えます(ゼロ点の代わりに `zero`、GSAS type 3 では幅 `sig1` と `alpha`,
`beta0`, `beta1` を同時に動かしてから `sig0`, `sig2`, `x`, `y`。Type0m では `sig1` → `sig0`, `sig2`,
`x`, `y`)。GSAS type 3 で立ち上がりが分解能より速い装置では α が上限 10 付近で
「決まっていません」と出ますが、フィットには害がないのでそのままで構いません。
GSAS-II の .instprm しか無い J-PARC のデータや、Type0m 以外(Type0、Type2)の装置ファイルでは
GSAS type 3 で計算します。その場合、ピーク位置の定義の違いで格子定数が 10⁻⁴ 程度ずれるので、
精密な格子定数が要るときは標準試料で DIFC とゼロ点を本プログラムで精密化し直してください。
試すなら `data/public/nac/PG3_22048.gsa` と `POWGEN_1066.instprm`、相は `NAC.cif`。

- **強度の単位**: GSAS 形式の TOF データはビン幅で割って counts/μs にして扱います(GSAS-II と同じ。
  SLOG のようにビン幅が変わるデータで必要)。x はビン中心に移すので点が 1 つ減ります。
- **複数バンク**: BANK が複数あるファイルは、読み込むバンクを選ぶか「すべてのバンク」で
  バンクごとにヒストグラムを追加できます(装置ダイアログはバンクごとに出ます。同時精密化は
  パラメータ表で `h0:`, `h1:` … を一緒にチェックするだけ)。
- **吸収**: バナジウム缶の μR を λ = 1 Å での値で入れます(ダイアログの「吸収 μR」、または
  `h0:sample:mu_r`)。反射ごとに波長に比例させて補正します。吸収の強い試料(Cd, Gd, B など)で
  長い d の反射が弱く出るときに精密化してください。
- **消衰**: 結晶子が大きく(数 μm 以上)強い反射が計算より弱いときは `h0:相:ext`(Sabine の係数、
  GSAS-II の Extinction と同じ単位)を動かします。実験室 X 線では普通は 0 のままで構いません。

## 7d. 連続データ(温度・時間系列)の逐次精密化

1 つ目のデータで精密化を済ませ、動かすパラメータにチェックを入れた状態で
「データ → 連続データを順に精密化」。ファイルを複数選んで「実行」すると、前の結果を初期値にして
順に精密化し、Rwp・χ²・各パラメータ(esd 付き)の表が出ます。「CSV に保存」で表計算ソフトへ。
スクリプトでは `kaisetsu.refine.sequential.refine_sequence` が同じことをします。

## 7e. 英語表示・大きなデータの保存

- 英語のメニューにするには `uv run kaisetsu-gui --lang en`(設定 "language" を "en" にしても同じ)。
  主要なメニュー・ツールバー・パネル名だけが英語になり、説明文は日本語のままです。
- 数万点を超えるデータは、スクリプトで `save_project(proj, path, external_arrays=True)` とすると

## 7g. Le Bail で自動解析(格子定数とプロファイルだけ。複数データ、放射光マイクロ XRD)

「データ → Le Bail で自動解析」。回折データ(複数可)と相の CIF(複数相なら複数)を入れて
「実行」すると、構造を使わない Le Bail 法で背景・ピーク位置・格子定数・ピーク幅を順に精密化し、
格子定数と esd、体積、Rwp を出します。CIF からは空間群と格子定数の初期値だけを使うので、
原子座標が無くても構いません。相同定のあとの格子定数チェック、Rietveld の前の下準備、μm ビームで
結晶粒が少なく強度が当てにならない放射光マイクロ XRD(マッピング)用です。1 本のデータを
ウィザードと同じ流れで Le Bail したいときは、ウィザードの「解析の種類」でも選べます(3 節)。
複数ファイル(マッピング、その場測定)は順に処理して「CSV に保存」、最後の結果は
「メインウィンドウで開く」で図を見たり続きを手で精密化したりできます。
スクリプトでは `kaisetsu.refine.lattice.refine_lattice` / `refine_lattice_batch` が同じことをします。

放射光の 2 次元検出器を積分したデータで気をつけること:

- **試料–検出器距離と波長の誤差は格子定数とほぼ完全に相関**します(距離 300 mm で試料位置が
  30 μm ずれると Δa/a = 10⁻⁴)。標準試料(CeO2、LaB6)を同じ条件で測って装置を校正し、
  「装置と試料の設定 → テンプレートに保存」で保存した *.kaisetsu-inst.json を使って、
  「位置の補正」は「動かさない」にするのが基本です。絶対値が要るときは標準試料を試料と同じ位置に
  置くか内部標準を混ぜます。相対値(マッピングやその場測定の変化)は 10⁻⁵ まで信用できます。
- 「位置の補正」を「試料–検出器距離」にすると sample:disp_y(Δ2θ ∝ sin 2θ)を動かします。
  反射が少ないか 2θ 範囲が狭いと格子定数と相関して両方決まらなくなるので、注意欄に出ます。
- 「ピーク幅」は既定で試料の広がり(ローレンツ成分 X, Y)だけを動かし、装置の U, V, W は
  テンプレートのままです。校正していない装置では「装置の幅も動かす」にします。
- Fit2D / Dioptas / pyFAI の .chi や .xy はそのまま読めます。強度が規格化されていてカウントで
  ないときは esd の絶対値が信用できません(χ² で割り戻しているので相対値は使えます)。

## 7h. コマンドラインで使う(バッチ処理)

GUI で保存したプロジェクト(`*.kaisetsu.json`)は、端末からも精密化できます。多数のデータを
夜のうちに処理する、解析の手順をスクリプトに残す、といった使い方のためです。

- インストーラで入れた場合: `kaisetsu-cli.exe`(インストール時に「PATH に追加」を付けていれば
  どのフォルダからでも `kaisetsu-cli`。付けていなければ `%LOCALAPPDATA%\Programs\kaisetsu\kaisetsu-cli.exe`)。
- Python で入れた場合(`uv tool install` / `pip install`): `kaisetsu` または `python -m kaisetsu`。

```
kaisetsu-cli refine   sample.kaisetsu.json                 標準手順で精密化して sample_refined.kaisetsu.json に保存
kaisetsu-cli refine   sample.kaisetsu.json --csv out.csv --reflections refl.csv --cif out.cif
kaisetsu-cli calc     sample.kaisetsu.json --unexplained peaks.csv   説明できないピークの一覧(d 値付き)
kaisetsu-cli refine   sample.kaisetsu.json --recipe current --cycles 20   いまチェックの入っている量だけ
kaisetsu-cli calc     sample.kaisetsu.json                 精密化せずに R 因子と診断だけ
kaisetsu-cli lattice  map_*.xy --cif CeO2.cif --inst bl.json --csv cells.csv   Le Bail 格子定数(多数のデータ)
kaisetsu-cli sequence start.kaisetsu.json T100.xy T200.xy T300.xy --csv seq.csv   連続データの逐次精密化
kaisetsu-cli presets                                      装置プリセットの一覧(--preset cu など)
kaisetsu-cli selftest                                     動作確認
```

`refine` のオプションは GUI の「標準の手順」ダイアログと同じです(`--no-coordinates`、`--no-adp`、
`--occupancy`、`--displacement`、`--preferred-orientation`、`--roughness`、`--no-cell-scan`、
`--no-kalpha2-trial`、`--no-humps`、`--cycles`)。入力のプロジェクトは上書きせず、`--out` か
`<名前>_refined.kaisetsu.json` に保存します。結果のプロジェクトは GUI で開いて図を確認できます。
`lattice` の装置は、GUI の装置設定で保存したテンプレート(.json)、GSAS-II の .instprm、GSAS の .prm、
またはプリセット(`--preset cu`、`co`、`synchrotron`、`neutron`、番号)で指定します。
`sequence` は既定ではプロジェクトでチェックの入っている量を動かし、失敗したデータでは格子定数を
振り直して再試行します。各コマンドの `--help` に全オプションがあります。終了コードは成功 0、失敗 1。

Python から直接使うなら `from kaisetsu.api import *`(README のスクリプト例)。

## 8. パラメータ名の規則

```
相:cell:a|b|c|alpha|beta|gamma      格子定数(晶系で自動的に拘束)
相:サイト:x|y|z                      分率座標(特殊位置の拘束は自動)
相:サイト:occ, uiso, u11..u23       占有率、変位パラメータ
h0:inst:zero|u|v|w|x|y|sh_l|pol         装置(h0 は 1 番目のデータ。詳細: p, z)
h0:sample:displacement|transparency|disp_x|disp_y|mu_r   試料
h0:bkg:0,1,2,…                      背景(Chebyshev 係数、固定点補間では各点の高さ)
h0:hump0:center|fwhm|height         非晶質ハンプ(中心、半値全幅、高さ)
h0:inst:kb_ratio                    Kβ 線の強度比(装置設定で「Kβ あり」のとき)
h0:相:scale|md_r|size|strain        スケール、選択配向 r、結晶子サイズ(μm)、微小歪み

g0:相:scale|delta1|delta2|sratio|spdiameter   相の PDF パラメータ
```

## 9. 困ったとき

- **背景が合わない(低角の立ち上がり、緩やかなうねり)**: 「データ → 背景の設定」で項数を増やす
  (読み込み時の既定 8、ウィザードは 12、目安 8〜16。公開データ 13 本では 8 → 16 項で 8 本が改善)。読み込み時にピークを避けて背景を自動推定しているので、項数を変えて
  「推定し直す」にチェックを入れると初期値も作り直されます。ピークが密な高角で背景がピークの裾を
  吸い始めたら項数を減らします。
- **ガラスキャピラリや非晶質成分の広いこぶ**: 標準手順(ウィザードも)がピーク幅のあとで残差の
  広いこぶを見つけ、背景にガウスのハンプを足して試します(採用するとログに中心と幅が出ます)。
  自動で拾わないときは「データ → 背景の設定」の「非晶質ハンプ」で個数と中心・幅を入れるか、
  「精密化 → 残差の点検」でこぶにチェックして「背景のハンプに追加」を押します。ハンプの
  パラメータ(`h0:hump0:center|fwhm|height`)は標準手順の「スケールと背景」で背景と一緒に動きます。
  Chebyshev の項数を 20 くらいに増やしても吸えますが、ピークの裾まで吸い始めるのでハンプのほうが
  素直です(PbSO4 に幅 12° のこぶを合成した試験: 12 項 Rwp 28%、20 項 11%、ハンプ 8%)。
- **「ガウス幅 Γ_G² が … で負です」と注意が出る**: U, V, W の組み合わせがデータの一部で負に
  なり、その範囲はガウス成分を 0 として計算しています(GSAS-II と同じ扱い)。フィットが良ければ
  実害は小さいですが、U, V, W は装置の特性としては意味を失います。装置として意味のある値が
  欲しければ W か U を固定するか、「精密化」→「ピーク幅が負にならないよう拘束する」を有効にして
  精密化し直してください(拘束すると Rwp が悪くなることがあります。付属の PbSO4 で 9.9% → 14%)。
  標準手順は負になったら U を初期値に固定してやり直し、それでも負なら V、さらに W
  (FWHM 0.01° 相当の最小値)の順に固定します。ピークがほぼローレンツ型の試料(Z-Rietveld の
  サンプルにある CaF2 など)では U, V, W がすべて固定されて X, Y だけが動きます。
  ローレンツ幅 Γ_L(X, Y, Z)や TOF の σ² も同じです。
- **「評価回数の上限で止まり、収束していません」と出る**: 精密化は段階ごとに反復回数を区切っているので、
  変数が多いときや初期値が遠いときに上限で止まることがあります。値は途中のものが入っているので、
  もう一度「精密化を実行」(F9)を押すと続きから動きます。何度押しても出るなら、発散しているか(次の項)、
  組み合わせでしか決まらない変数(ログの「相関」の注意)が混ざっています。逐次精密化では表の備考に
  「未収束」と出ます。
- **発散する(Rwp が増える・値が飛ぶ)**: Ctrl+Z で精密化前の値に戻すか「すべて初期値に戻す」で戻し、
  いったん「すべて固定」してスケールと背景だけからやり直す。
  ピーク位置が大きくずれていれば先にゼロ点か格子定数だけを動かす。
- **格子定数が初期値から動かない / 計算ピークが観測とずれたまま**: 初期値が「谷の外」で、最小二乗が
  動かせない状態です。標準の手順(ウィザードも)の「格子定数の初期値を振る」が ±1〜3% の範囲で
  探します。文献の格子定数が試料と大きく違う(固溶体、温度)ときは、先に「データ → Le Bail で
  自動解析」で格子定数を決めて相の設定に入れるか、「初期値を振る」を付けて標準手順を
  走らせてください。
- **格子定数の絶対値が要る(試料変位・ゼロ点と区別したい)**: 格子定数とゼロ点(試料変位)は強く
  相関します。ゼロ点を先に動かすと、格子定数のずれをゼロ点が吸って R 因子だけ良く見える極小値に
  落ちることがあります(相見, 電気化学 94, 264 (2026) の CeO2 の例)。確実なのは内標準法です。
  Si(NIST SRM 640 系、a = 5.43118 Å)などを質量比で 1/5 ほど混ぜて測り、Si を第二相として
  足し、Si の格子定数を固定したままゼロ点(平板なら試料変位)を動かして決め、その後に試料の格子定数を
  動かします。3d 遷移金属酸化物なら Si を 1/5 混ぜると両方のピークが同程度の強さになります。
  装置の校正(標準試料で決めたゼロ点・試料変位)があればそれを固定して使うのが次善です。
- **ピークが細すぎる / 太すぎる**: 装置設定で W(全角に効く)を観測の FWHM² の目安に合わせる。
  Cu Kα の実験室装置なら W ≈ 0.003〜0.01 deg²。
- **強度比が合わない**: 選択配向(`h0:相:md_r`、配向軸は板状結晶の面)、占有率、U_iso の順に疑う。
  合わないピークにカーソルを置いて hkl を確かめ(4 節)、特定の面(00l、h00 など)ばかりが強すぎる・
  弱すぎるなら選択配向で、その面を「相の設定」の配向軸にする。
- **特定のサイトの U_iso だけ目立って大きい(他の 4 倍以上、B > 2.4 Å²)**: R 因子が良くても
  初期モデルの空間群が違う、サイトの元素や占有率が違うサインです(PbNiO3 を Pnma で解くと
  O の B が 3.9 Å² になり、Pbn21 なら正常。文献の空間群が誤っていることもあります)。
  精密化のあとの「注意:」に出ます。空間群の候補を変えて Rwp と U_iso を比べてください。
- **U_iso が負になる**: 吸収の強い試料を平板に詰めたときの表面粗さ効果が典型(LaB6 のサンプルで再現できる)。
  「標準の手順」で「表面粗さを動かす」を付けるか、`h0:sample:rough_a` を動かす(1 = 補正なし、小さいほど粗い。b は 1 に固定)。
  背景が高すぎる・偏光係数が合っていないときにも起こる。精密化のあとに出る「注意:」のログも参考にする。
- **占有率を動かすと esd が巨大になる**: 占有率 1 で混合でもないサイトの占有率はスケール因子と区別
  できない。「標準の手順」の占有率は混合サイトと部分占有サイトだけを動かす。混合サイトは占有率の和が
  自動で保たれる(後に書かれた種が従属)。
- **差のプロットに相のピークでない山が残る**: 「精密化 → 残差の点検」で、相の反射で説明できない
  ピーク(不純物・試料台)と広いこぶ(非晶質成分)の候補が出る。チェックして「除外領域に追加」
  「背景のハンプに追加」を押す。反射の位置にあるのに強度が合わないもの(「強度の不一致」)は
  除外せず、占有率・選択配向・第二相を疑う。自動では除外しない(構造の問題まで異物扱いに
  なるため)。精密化のあとの「注意:」にも候補が出る。
- **第二相を探したい(説明できないピークを他のソフトに渡す)**: 「残差の点検」の表には各ピークの
  d 値(精密化したゼロ点・試料位置の補正を外した値)が出ます。「ピーク一覧をコピー」でタブ区切りの
  一覧(位置、d 値、高さ、最大比、近い反射)がクリップボードに入り、表計算ソフトや検索・同定
  プログラムに貼れます。「ピーク一覧を CSV に書き出す…」で同じ一覧をファイルにできます
  (コマンドラインは `--unexplained peaks.csv`)。一覧には「強度の不一致」も種類付きで入ります
  (第二相のピークが相の反射に重なっていることがあるため)。kaisetsu は第二相を自動では
  探しません。見つけた相の CIF を「相を追加」で足してください。
- **Le Bail をしたい(構造を使わずに格子定数とピーク形だけ)**: 一番手軽なのはウィザードの
  「解析の種類」で Le Bail。複数ファイルなら「データ → Le Bail で自動解析」、読み込み済みの
  プロジェクトなら「データ → 相の設定」で相を Le Bail 法にして「標準の手順」(7a 節)。
- **Le Bail / Pawley で強度が合わない**: Le Bail は各反射の積分強度(面積)を観測に合わせるので、
  強度そのものは必ず合います。合って見えないときは別の原因です。(1) ピークの高さだけ違う →
  幅・形の問題。U, V, W, X, Y(と非対称 S/L, H/L)を動かす。(2) 計算ピークの位置がずれている →
  格子定数・ゼロ点。ずれたまま動かないなら「格子定数の初期値を振る」。(3) 計算ピークが無い
  ところに観測ピークがある → 空間群の消滅則が違うか第二相(「精密化 → 残差の点検」)。
  (4) 完全に重なった反射は観測で分けられないので、初期値の比(構造から作った場合は構造の比)のまま
  分け合います。v0.1.10 より前には、データ範囲のすぐ外(上限 + 2°)にある反射が裾だけで強度を
  受け取って桁違いに膨らみ、Le Bail 全体が崩れる不具合がありました(PbSO4 で標準手順の Rwp が
  10^14 %)。更新すれば直ります。「精密化」ボタンは Le Bail 相があれば、強度の更新と最小二乗を
  Rwp が動かなくなるまで(最大 5 回)繰り返します。
- **Kα1 だけのはずなのに合わない / Kα2 を入れたら悪くなった**: 標準の手順の「Kα2 なしも試す」が
  ピーク幅のあとで両方を比べ、良い方を採る(ログに「Kα2 を外しました」か「Kα2 ありのまま」)。
  手で切り替えるなら装置設定の Kα2 の強度比を 0 にする。
- **軽原子(O, C, Li)の U_iso が負や下限 −0.05 に張り付く**: 標準手順は、重原子が散乱を支配する相では
  最初から軽原子の U_iso を共通にし、そうでなくても個別に動かして負か下限になったサイトがあれば
  共通にしてやり直します(ログに出ます)。手で解くときも同じことをしてください。重原子と共存する軽原子の U_iso は
  実験室 X 線では個別に決まらない。標準の手順は重原子が散乱能の 70% 以上を占めるとき軽原子の
  U_iso を共通の 1 つにする(ログに出る)。手でやるなら 0.01 Å² 程度に固定する。
- **CIF が読めない**: 空間群の記号か対称操作が必要です。VESTA 等で書き出し直すと読めることが多い。
  座標が `?` や空欄のサイトがあると止まります(小数で書く)。
- **CIF を読んだ後の組成・多重度が論文と違う**: 読み込み時の警告(「原点選択」「多重度が CIF の … と
  合いません」「像どうしが … Å しか離れていません」)を見る。原点選択の違いなら記号に `:1` / `:2` を
  付ける、座標の桁落ちなら桁を増やすか対称操作を CIF に書く。

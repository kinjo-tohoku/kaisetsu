# 公開データ(opXRD)での「一発の標準解析」と「真面目な解析」の比較

- 日付: 2026-10-13
- データ: opXRD(Open Experimental Powder X-ray Diffraction Database、Hollarek ら 2025、CC BY 4.0、
  Zenodo 10.5281/zenodo.15298026、92,552 本)。構造ラベル付きは CNRS/IRCP(PSL)の COD 由来の
  pdCIF 891 本(全原子セル、空間群なし)と HKUST-A の 21 本。ここでは CNRS から、波長が分かって
  いて原子数が多すぎない(≤ 48)単相のパターンを晶系ごとに選んだ 13 本を使った。
- 読み込み: `kaisetsu.io.readers.opxrd`(JSON)。構造は P1 の全原子セルなので
  `kaisetsu.crystal.symmetry.find_symmetry`(spglib)で空間群と非対称単位に戻した。
  混合サイト(Ti/Nb など)はラベルで占有率が失われている(各元素とも 1)ので、重なった原子の
  占有率を等分にする(13 本中 4 本)。部分占有サイトの占有率も失われているが、これは直せない。
- 計算: kaisetsu 0.1.0(コミット f1a231c)、Windows 11、Python 3.14。1 本あたり標準 1〜18 分、
  真面目 7〜58 分(13 本を並列)。

## 手順

**標準(一発)**: GUI のウィザードの既定と同じ。装置はプリセット(実験室 Cu Kα: Ni フィルタ、
Kα1+Kα2、U, V, W = 0.004, −0.003, 0.004、X = Y = 0.02、SH/L = 0.04、偏光 0.5、Bragg-Brentano。
Co Kα も同様。放射光(λ < 1.2 Å): キャピラリ Debye-Scherrer、U, V, W = 0.0005, −0.0003, 0.0005、
偏光 0.98)、背景 Chebyshev 8 項、全範囲、`standard_recipe`(座標・U_iso あり、ゼロ点、粗さなし)。

**真面目**: 人が順に確かめることを自動化した(`scratchpad/opxrd_stage2.py`)。採否は Rwp が
0.3 以上(絶対値、5 と 6 は 0.2)下がるかで決める。各段階は累積(前の段階で採用したものは残す)。

0. 混合サイトがあれば占有率を精密化(`standard_recipe(occupancy=True)`)
1. 残差に残る鋭いピーク(相の反射で説明できない = 不純物・試料台)を除外領域に。
   幅が FWHM の 4 倍より広い残差(非晶質のこぶ)はガウスのハンプとして背景に足す
2. ラベルが Kα1 だけのとき、Kα2 なし(モノクロメータ)で合うか
3. 背景を 16 項に
4. 選択配向(March-Dollase。軸の候補を短い精密化で選んでから本精密化)
5. 表面粗さ(平板)/ 吸収 μR(キャピラリ)
6. ゼロ点でなく試料変位
7. Stephens の異方的歪み

**Le Bail**(同じ装置既定、構造を使わない)の Rwp も「プロファイルと背景だけの下限」として並べる。
Le Bail が Rietveld の真面目な解析より明らかに良ければ、残りの差は構造モデルの問題。

### 標準の一発で何がダメだったか(頻度順)

1. **背景の項数**(8 → 16 で改善 8 本)。実験室データの低角の立ち上がり(空気散乱、試料台)や
   キャピラリのこぶに 8 項では足りない。差は 0.3〜3 ポイント。項数を増やすだけで済むので、
   ウィザードの既定を 12 項程度に上げるか、残差の低周波成分を見て項数を提案するのがよい。
2. **相の反射で説明できないピーク**(除外が採用されたのは 6 本。うち 150 と 78 はこぶ)。不純物(1047: 39.4°, 41.1°)、試料台や器具
   (228: 82.1〜82.4° に Kα 二重線が見える鋭いピーク。α-Fe 211 と同じ位置なので金属の異物)、
   第二相(923: 34.7°, 38.4°, 44.7°)。標準は除外しないので、その周りの背景とプロファイルが
   引きずられ Rwp が 2〜5 ポイント悪くなる。一方、自動の除外規則(「近くに計算反射がない、
   または計算強度が残差の半分未満」)は、**構造モデルの強度が間違っている反射**まで異物と
   みなして除外してしまった(250 の 12.6°、923 の 16°・31〜33°・46°・51°)。人がやるなら
   「反射の位置に観測ピークがあるのに強度が合わない」は構造(占有率・配向)の問題として扱う。
   GUI では候補を示して人に選ばせる形にすべきで、自動除外にはしない。
3. **非晶質のこぶ**(150 の 10°, 22°, 50°、78 の 19〜22°)。Chebyshev では追えない。
   ガウスのハンプ 3 つを背景に足すと 150 は全範囲で Rwp 4.10%(除外より良い)。自動検出
   (残差を 10 FWHM で平滑化して幅 > 4 FWHM)は雑音の多いデータで鋭いピークの規則に先に
   引っかかって働かなかった。平滑化した残差でまずこぶを探し、それを引いてから鋭いピークを
   探す 2 段構えにする必要がある。
4. **Stephens の異方的歪み**(5 本で採用、183 では 5.93 → 3.63)。層状化合物(SnSe、
   AgCrP2S6)や単斜晶では等方的な U, V, W, X, Y では足りない。ただし 926 では Stephens の
   係数が決まっていない(esd ≫ 値)のに Rwp が 0.4 下がった。過剰パラメータの疑いがあるので、
   GUI の診断に「係数が決まっていない」を出す現状の扱いでよい。
5. **選択配向**(4 本で採用)。放射光キャピラリでも r = 0.95〜1.12 が採用された。
   March-Dollase の軸候補を短い精密化で選ぶ方式は機能した。
6. **Kα2 の有無**(2 本)。ラベルの波長だけでは分からず、試してみるしかない。
   Kα2 なしで Rwp が 1〜2 ポイント下がるので、ウィザードで「Kα2 なしも試す」を提案できる。
7. **混合サイトの占有率**(4 本で試行、採用 0)。等分から精密化しても Rwp は 0.03〜0.2 しか
   変わらない。X 線で Ti/Nb、Ga/Sb、Ba/Ca の比は決まらない(Ba/Ca は決まるはずだが 926 は
   モデル全体が粗い)。
8. **表面粗さ・試料変位**(採用 0)。粗さ a は 1(補正なし)の上限に張り付くか、動いても
   Rwp は 0.003 しか変わらない。U_iso が負になるのは粗さでは説明できない。

### 真面目にやっても残るもの

- **軽原子の U_iso が下限 −0.05 Å² に張り付く**(150 の Li と C、584 の O、78 の O、250 の
  Fe/Te)。Te や Bi と共存する軽原子の U_iso は実験室 X 線では決まらない。人なら O の U_iso を
  0.01 に固定するか全部共通にする。標準手順にも「重原子が散乱を支配するとき軽原子の U_iso は
  共通または固定」の規則が要る(残課題)。
- **構造モデルが試料と違う**。Le Bail が真面目な Rietveld より明らかに良い 228(4.5 対 7.6)
  と 250(3.0 対 4.5)。250 は Fe1 の U_iso が 0.29 Å² と異常に大きく、本来は部分占有(ラベルで
  失われた)。228 は 50.3° と 38.5° の反射が計算の 2 倍以上あり、U_iso が全部負、ゼロ点 0.18°
  と大きい。多形か積層不整か、単純な軸でない配向の可能性がある。923 は配向 r = 1.43 と強く、
  13.2° の 00l 型反射だけ鋭い(異方的な幅)。これらは機械的な手順では直らず、人が構造を疑う
  必要がある。
- **放射光の鋭いピークの形**(794、1049、416。GOF 3.7〜9.3)。FWHM 0.02° 級のピークで
  TCH 擬 Voigt + 軸発散の既定(SH/L = 0.01)が形を追えず、最強ピークの残差が Rwp を決める
  (1049 の 8.5° で ±10 万カウント)。標準手順は SH/L を動かさないので、放射光では SH/L も
  動かす段階を加えるか、別の非対称関数が要る。1049 と 416 の Le Bail(11.3、13.4)が真面目な
  Rietveld(10.8、13.1)より悪いのも同じ理由(Le Bail でもプロファイルは同じ)。
- **計数の多いデータの GOF**(78: 7 × 10⁵ カウントで GOF 11)。Rwp 3.95% でも統計誤差が
  小さすぎて χ² が大きい。Rwp と差のプロットで判断するのが正しい。

### 途中で見つかり直したプログラムの問題

- **Le Bail の抽出強度に背景の誤差が乗る**(コミット f1a231c)。反射ごとの計算窓(低角側
  50 幅 + 軸発散、高角側 75 幅。GSAS-II と同じ)の裾まで Rietveld 分配に使っていたので、
  孤立した反射では窓の中の背景の誤差が全部その反射の強度に加わる。放射光(FWHM 0.025°、
  窓 4°)で弱い反射が数倍に膨らみ、Le Bail が Rietveld より悪かった(794: 12.6%、1049: 25.7%)。
  反射自身の寄与がその最大値の 1% 以上の点(±3.5 FWHM)だけで分配するようにして 6.8%、11.3%。
  実験室データでも 228: 5.0 → 4.5、923: 10.6 → 6.0、250: 3.2 → 3.0。
- **標準手順で Le Bail 相の強度更新が足りない**(コミット 04a8cef)。段階ごとに 1 回しか
  更新しないと、幅が合わないうちに抽出強度が崩れる(1047: 23.6 → 11.1%、926: 23.6 → 11.9%)。最初に 5 回、
  各段階で 3 回ずつ更新する。
- **opXRD の混合サイト**(コミット 07212f2)。Ti と Nb が同じ位置に占有率 1 で重なっていると
  Sr(Ti,Nb)O3 の 111 反射が消え(f_Sr − f_Ti − f_Nb + 3 f_O ≈ 0)、Sr の U_iso が負になる。
  重なった原子の占有率を等分にして 794 は 18.3 → 7.9%。
- **格子定数とピーク幅が発散するとメモリを使い尽くす**(416 の一発解析を修正前のコードで
  再実行したものが 4 時間で 21 GB まで膨らみ、1 回目は落ちていた)。修正前の Le Bail(上の背景
  混入)で抽出強度が崩れると、幅が 0.027° から 8° に、格子定数が 4.06 × 4.08 × 12.66 Å から
  6.3 × 8.9 × 22.5 Å(体積 6 倍)に流れる。Le Bail は反射が増えるほど合うので、格子が大きく
  なる方向に止まらない。hkl の候補は格子定数の 3 乗、ピーク窓は幅に比例して増える。
  hkl の候補(2e7 個)とピーク窓の点数(1e8 点)に上限を付けて `PatternSizeError` で止め、
  最小二乗はその試行点を不可として続け、レシピは段階前の値に戻して知らせる。格子定数の範囲も
  初期値の 0.5〜2 倍にした。ガードを入れて同じ再現を回すと 24 分、3 GB で止まる。

### 所見(パターンごと)

- **499 Na(Ti,Nb)O3(Co Kα)**: 一発で 2.32%、GOF 1.5。何もしなくてよい例。Ti/Nb の U_iso が
  わずかに負(−0.006)だが、どの処置でも直らない(Na 欠損か Ti/Nb 比が違う)。
- **794 Sr(Ti,Nb)O3(放射光)**: 背景 16 項で 6.35%。残差は 110 の形(鋭すぎる)と、100・111・

- **150 Li2TeC2(Cu Kα1+Kα2)**: 非晶質のこぶ(キャピラリのガラスか空気に弱い試料の分解物)
  3 つ。除外で 4.49%、ハンプで 4.10%。Li と C の U_iso は決まらない(Te が散乱を支配)。
- **1047 Pd2(Ga,Sb)(Cu Kα1)**: 39.4°・40.7°・41.1° に相の反射がない小さなピーク(不純物)。
  Kα2 なしで 7.1 → 5.2、Stephens で 4.0%。Ga2/Sb2 サイトの U_iso が負(占有率を動かしても
  改善なし → Ga/Sb の分布が違う)。
- **1049 Pr2In2S4O2(放射光 0.495 Å)**: 背景 16 と配向 [001] で 10.8%。残差は最強ピークの形。
  Le Bail(11.3%)も同程度なのでプロファイルの限界。
- **183 SnSe(放射光)**: 配向 [001] と Stephens(異方的歪み)で 6.3 → 3.6%。層状化合物の典型。
- **416 La/In/S/O(放射光)**: 8.05°・8.7°・9.1° に弱い未同定ピーク(除外は 0.2 の改善で不採用)。
  背景 16・配向 [011]・Stephens で 13.1%、GOF 9。S と O の U_iso が負、V が決まらない。
  プロファイル(1049 と同じ)と構造の両方に問題がある。
- **926 (Ba,Ca)CO3(Cu Kα1、30,464 点)**: Kα2 なし + 背景 16 + Stephens で 7.0%、GOF 1.4。
  Stephens の係数は決まっていない。Ba/Ca 占有率の精密化は 0.17 の改善で不採用。
- **250 NbFe3Te3(Cu Kα1)**: 12.6° の「異物」は相の反射(計算強度が小さすぎた)。Fe1 の
  U_iso 0.29 Å²、他は負 → 部分占有が失われている。Le Bail 3.0% なので構造モデルの問題。
- **228 NbBr4(Cu Kα)**: 82.1〜82.4° の鋭い二重線(異物)の除外で 13.4 → 8.2、背景 16 で
  7.6%。50.3° と 38.5° の強度不一致、全 U_iso 負、ゼロ点 0.18° は残る。Le Bail 4.5%。
- **923 AgCrP2S6(Cu Kα1)**: 8 領域除外(真の異物は 34.7°・38.4°・44.7°)+ 配向 [100]
  r = 1.43 で 5.3%。13.2° と 29.7°・30.8° の強い反射の形が合わない(異方的な幅)。
  Stephens は 0.29 の改善で閾値に届かず不採用。
- **78 V2P4O14(Cu Kα1)**: 19〜22° の背景のこぶ(弱い反射が乗っている)を除外、背景 16 で
  4.0%。計数が多く GOF 11。O の U_iso 負。
- **584 BiNiPO5(Cu Kα)**: 背景 16 + Stephens で 3.1%。O の U_iso が下限 −0.05 に張り付く。

### 使い方への示唆

- 一発の標準解析は、単相で異物がなく背景が素直なら 2〜6% で止まる(499、584、250、78)。
  それ以外は 9〜17% で、「何が悪いか」は差のプロットを見れば分かる種類のもの(異物ピーク、
  こぶ、Kα2 のずれ)。GUI の診断にこれらの候補を出す価値がある。
- Le Bail を並べて出すと「プロファイルの限界」と「構造モデルの問題」を切り分けられる。
  ウィザードに「Le Bail も同時に走らせる」選択肢を付けるとよい。

## 標準手順の改善後(2026-10-15)

上の「標準の一発で何がダメだったか」に沿って標準手順を直し、同じ 13 本で改善前後を比べた
(`scratchpad/opxrd_stage3.py`、コミット直前のコード、装置の既定値は上と同じ、全範囲)。

- 改善前: 背景 8 項、`standard_recipe(asymmetry=False, try_no_kalpha2=False, light_atom_uiso=False)`。

  以上下がれば採用)、放射光(λ < 1.2 Å)では SH/L も動かす、重原子が散乱能の 70% 以上を占める相では
  軽原子(Z ≤ 10)の U_iso を共通にする、対象の無い段階は飛ばす。

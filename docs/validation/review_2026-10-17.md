## 1. 特殊位置の定数項

`position_constraint` はサイト対称操作の平均像から正しい不変点 xs(並進込み)を求めていたが、
従属座標の定数項を `constraint_from_projector` の中で `P @ xs`(変位の射影)から計算していた。
射影は並進を落とすので、y = x/2 + 1/2 の関係が y = x/2 になり、精密化の最初の `evaluate_ties` で
座標が別の点に飛ぶ(座標を動かさなくても起きる)。定数だけの特殊位置(Pnma 4c の y = 1/4 など)は
`fixed` 側で xs を直接使うので無事だった。これが PbSO4 の検証で見つからなかった理由。

再現(P 6/m m m、a = 4、c = 6 Å、Si (0.2, 0.6, 0)、中性子 1.5 Å):

| | 修正前 | 修正後 |
|---|---|---|
| 拘束適用後の座標 | (0.2, **0.1**, 0) | (0.2, 0.6, 0) |
| \|F(100)\|² | 114.17 → **247.44** | 114.17 → 114.17 |
| \|F(110)\|² | 163.34 → **9.10** | 163.34 → 163.34 |

影響範囲: 手元の COD の CIF 1,100 件(22,394 サイト)で、拘束を評価すると座標が変わるサイトを数えると
13 件 25 サイト。空間群は Ia-3d(48g の (1/8, y, 1/4 − y))、I4/mcm(8h の (x, x + 1/2, 0)。傾斜ペロブスカイトの
酸素)、P4bm、I41/amd、P-421m(メリライト)、P213、Pn-3m。ガーネットの 24c / 24d / 16a のような定数だけの
位置は該当しない。公開済みの「自動 vs 著者」の比較(`auto_vs_manual.md`)の表には該当件は無い。

修正: `constraint_from_projector(..., project_values=False)` を足し、座標の拘束では xs を射影し直さずに
定数項を xs[j] − Σ c xs[pivot] で求める。ADP と Stephens の対称化は原点を通る線形部分空間なので従来どおり
射影を使う。回帰テスト `tests/unit/test_constraints_affine.py`(5 つの空間群で座標・多重度・\|F\|² の不変、
主座標を動かしたときの追従)。

## 2. Friedel 対の平均

反射はラウエ群で代表 1 本にまとめ、多重度は hkl と −h−k−l の両方を数える。非中心対称構造では
f'' のため \|F(h)\|² ≠ \|F(−h)\|² なので、代表 1 本の \|F\|² に多重度を掛けると代表の選び方で強度が変わる。
正しくは (\|F(h)\|² + \|F(−h)\|²)/2 = \|A\|² + \|B\|²(A = Σ(f0 + f')T e^{iφ}、B = Σ f'' T e^{iφ})。

再現(ZnS、F -4 3 m、a = 5.41 Å、Cu Kα1):

| | 修正前 | 修正後 |
|---|---|---|
| 111 の \|F\|²(実装) | 12075.24(代表 1 本) | 11917.53(平均) |
| 111 の相対誤差 | +1.32% | 2e-16 |
| 全座標を反転したときのパターンの最大変化 | 2.61%(最大強度比) | 3e-16 |

GSAS-II 5.7.4 の粉末の分岐(`GSASIIstrMath.py` `StructureFactor2`、1248 行)も代表 1 本の
(Σ fas)² + (Σ fbs)² を使っていて、平均形 Σ fas² + Σ fbs² はコメントアウトされている。つまり修正前は
GSAS-II と同じ近似だった。修正後は非中心対称の X 線で GSAS-II と 1% 程度ずれることがあるが、
これまでの GSAS-II 突き合わせ(PbSO4、ダイヤモンド、Ni、NAC の中性子)は中心対称か中性子なので影響なし。

修正: `structure_factor_parts`(A、B を返す)と `powder_structure_factor_squared`(\|A\|² + \|B\|²)を足し、
CW・TOF のパターン計算、半解析ヤコビアンの `_f2_for`、Le Bail の初期強度で使う。`structure_factors`
(複素 F)はそのまま。回帰テスト `tests/unit/test_friedel_powder.py`。

## 3. 跨ぎ拘束のヤコビアン

背景・スケールの解析列は自分のヒストグラムの行だけを埋めて `continue` するので、他のヒストグラムの
パラメータが従属していても連鎖が入らない。残差側は拘束を適用するので、最適化する関数と微分が食い違う。

再現(背景だけの 2 データセット、観測 1 と 3、`h1:bkg:0 = h0:bkg:0`、初期値 1):

| | 修正前 | 修正後 |
|---|---|---|
| 第 2 ヒストグラムの解析列のノルム | 0 | 4.5826(数値微分と一致) |
| 半解析で精密化した共通背景 | 1.0(初期値のまま、success=True) | 2.0(厳密解) |

GUI には拘束を編集する画面が無く、標準の手順が作る拘束(軽原子 U_iso の共通化)は同じ相の構造パラメータ
同士で、`_perturbed` → `_f2_for` が相ごと再計算するので正しかった。起きるのは API やプロジェクトファイルで
ヒストグラムや相を跨ぐ拘束を書いた場合。

修正: 従属パラメータを持つ主パラメータのうち、ヒストグラムのもの(背景・スケール・選択配向)と、
他の相に従属を持つ構造パラメータは数値微分に落とす。回帰テスト `tests/unit/test_jacobian_ties.py`。

## 4. CIF の占有率 0

`float(s.occ) if s.occ > 0 else 1.0` で明示された 0 も「値なし」と同じ扱いになっていた。gemmi の挙動を
確かめると、列が無いとき・`?`・`.` は 1.0、明示の 0 は 0.0、負の値はそのまま返す。修正後は `isfinite` で
判定して 0 を保ち、負はエラー(`ValueError`、日本語の案内付き)。自前の `write_structure` → `read_structure`
の往復で [1, 0.5, 0] が保たれる(修正前は [1, 1] になり単位胞質量が 28.09 → 44.08 g/mol に変わった)。
回帰テスト `tests/unit/test_cif_occupancy.py`。

## 5. 未収束の表示

`FitResult.success` を見ずに `finished(True, "完了: …")` を送っていた。scipy の least_squares は関数評価回数の
上限(max_nfev = 3 × max_cycles)で止まると success=False を返すが例外にはならない。標準の手順は段階ごとに
回数を区切るので途中段階が上限で止まるのは設計どおりだが、最後の段階の状態は利用者に見えるべき。

修正: `convergence_note(fit)` を足し、ワーカーの「完了」の 2 行目に「注意: 評価回数の上限で止まり、収束して
いません(値は途中のものです)。「精密化を実行」をもう一度押すと続きから動きます」を添える。逐次精密化は
行の備考に「未収束(評価回数の上限で停止)」(esd を付け直すための 1 サイクルの精密化は判定に使わない)。
回帰テスト `tests/gui/test_worker_unconverged.py`、`tests/unit/test_sequential_unconverged.py`。

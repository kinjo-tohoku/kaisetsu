# GLM / DeepSeek によるコードレビューの評価と対応(2026-10-17、v0.1.14 に対して)

v0.1.14(02d1abe)の `src/kaisetsu/` を、ユーザーが別のモデル 2 つ(GLM、DeepSeek V4.1 Flash)に
読ませたレビューの評価。原文は `review_glm_deepseek_2026-10-17_full.md`。
どちらも「確実に壊れる・黙って物理的に間違う」ものは見つからなかったと結論しており、
指摘はすべてコードと突き合わせて再現・反証した上で、採る/採らないを決めた。

**一番大きかったのは、指摘そのものではなく裏取りの副産物**: DeepSeek #4(GSAS 旧 .prm の偏光の空欄)を
確かめるために GSAS-II 5.7.4 本体に PbSO4 の `INST_XRY.PRM` を読ませたところ、kaisetsu の
`CWInstrument.from_gsas_prm` は λ2 があるときに **Kα2 の強度比と偏光の欄を取り違えて** いた
(GSAS-II は I(L2)/I(L1) = 0.5、Polariz. = 0.7。kaisetsu は 0.7 と 0.5)。GSAS-II のソースのコメント
「pola & ratio」の順を信じて写していたが、実際の対応は `names` の並びで決まり偏光が先。
実験室 X 線の旧 GSAS .prm を読んだ人は Kα2 が 1.4 倍の強さで計算され、偏光も違っていた。
単波長(放射光・中性子)の .prm は影響しない。

## GLM の指摘(9 件)

| # | 件名 | 判定 | 対応・根拠 |
|---|---|---|---|
| 1 | ピーク位置の補正の候補選びで、換算 χ²(自由度で割った値)に Hamilton 型の比検定を当てている | 採用 | 指摘のとおり。自由度で割る前の Σw(y_o − y_c)² で比べるように(`_PositionTrial.ssq`)。偏りは「変数の少ない側の自由度 / 多い側の自由度」倍で、自由度 5000 なら閾値が 0.02% 厳しい程度(閾値 0.2% の 1 割)。`tests/unit/test_position_trial.py` の採否は変わらない |
| 2 | `numerical_jacobian` で現在値が下限ちょうど・刻みが上下限の幅より大きいと 0 で割って NaN | 採用 | 再現(刻み 1.0、範囲 [0, 0.5]、現在値 0)。`bounded_step` を切り出し、前進 → 後退 → 両側に余地が無ければ広い側に刻みを縮める。上下限が一致していれば列を 0 にする |
| 3 | `project_jacobian` の数値微分の後退差分が下限を見ない | 一部採用 | 「クリップでスケールがずれる」は誤り(`_perturbed` は丸めない)が、下限側を見ないのは本当。#2 と同じ `bounded_step` に統一 |
| 4 | ヒストグラムごとの R_exp・χ² が全体の変数の数で自由度を引く | 不採用(明記) | FullProf の多パターン精密化と同じ約束。単一ヒストグラムでは無関係。`Project.rfactors` の docstring に書いた |
| 5 | `done` が常に True で数値微分への fallback が死んでいる | 採用(整理) | 事実。ただし相がどのヒストグラムにも無ければ数値微分でも 0 列になるので挙動は同じ。変数を消して意図をコメントに |
| 6 | 格子定数走査で span ≥ 3% のとき同じ範囲を 2 回走査 | 採用 | 再現(stub で数えて 2 回 → 1 回)。結果は変わらず時間だけ |
| 7 | 逐次精密化の x_min / x_max が単調に狭まる | 採用 | 最初の設定を保ち、データが届かない分だけ狭める(前のファイルで狭めた範囲を次に引きずらない)。20–60° の次に 20–80° を読むと 60° のままだった |
| 8 | MEM ZSPA の λ 半減が履歴に残らない | 不採用 | 履歴は成功した反復の (λ, C) の列として使っている。半減は診断の対象でない |
| 9 | 多波長の `intensity_total` が窓の切れた成分を足さない | 不採用 | 分配(I_obs)も R_Bragg も窓内の寄与と対で使うので整合している。Kα2 が範囲外の反射で Kα1 だけ数えるのは意図 |

## DeepSeek の指摘(13 件 + 参考)

| # | 件名 | 判定 | 対応・根拠 |
|---|---|---|---|
| 1 | 球面調和関数の係数の数が基底と合わないと黙って選択配向が消える | 採用(記録) | `build_parameters` が 0 に戻すのは以前から。黙って戻さずログに「係数の数 n が基底の数 m と合わないので 0 に戻した」を残す。保存ファイルは次数と係数を一緒に書くので、普通の読み込みでは起きない |
| 2 | `canonical_hkl` の整数キーが回転像で桁あふれ | 採用(理屈) | 六方晶の h + k は入力の最大成分を超えるので理屈は正しい。位取りを回転像込みの最大で決めた。ただし P6/mmm・P-3m1・R-3m・P4/mmm・Pm-3m の 280 反射 × 全ラウエ回転で旧実装の誤った代表は 0 件(最上位桁のあふれは順序を保つ)。`generate_reflections` は影響しない |
| 3 | `find_symmetry` が異方性 U を捨てて U_iso = 0 にする | 採用(U_eq) | 標準設定への変換で U_ij の向きが変わるので持ち越さず、等価等方 U_eq = (1/3) Σ U^ij a*_i a*_j a_i·a_j に落とす(Fischer & Tillmanns 1988)。種類の区別にも U_eq を使う。本体の流れでは未使用(opXRD 用) |
| 4 | GSAS 旧 .prm の偏光が空欄で 0.0 | 不採用 → 別の実害を発見 | 空欄は GSAS-II の `sfloat` も 0.0 で、手元の実ファイル(11-BM、PbSO4、D1A)は全部欄がある。裏取りで上記の**比と偏光の取り違え**が見つかり修正。実ファイルで GSAS-II と一致するテストを追加 |
| 5 | `fcj_pseudo_voigt` の `n_quad` が accurate 法で無視される | 採用(明記) | 事実。accurate 法は一括カーネルが点数を決める。docstring に「gsas 法のみ」と書いた |
| 6 | `ChebyshevBackground` の係数が空だと NumPy の英語の例外 | 採用 | `__post_init__` で日本語の `ValueError` |
| 7 | 散乱因子表の `Cval` / `Hiso` / `Sival` に届かない | 採用 | `resolve` で生のラベルを先に表と照合。`AtomSite` の元素記号は `split_species` を通るので、構造の散乱種としては引き続き使えない(直接 `f0("Cval", s)` を呼ぶ用途のみ) |
| 8 | `Lattice.reciprocal` の `acos` に丸めの余裕が無い | 採用 | 引数を [−1, 1] に丸める |
| 9 | `Radiation` が λ3 と強度比を検査しない | 採用 | λ3 > 0、比は 0 以上の有限値 |
| 10 | 候補の上限 floor(a / d_min) に余裕が無く、境界の反射を落としうる | 採用 | 再現(a = 5.1、d_min = a/3 × (1 + 1e-13) で (3 0 0) が落ちる)。採否の判定と同じ相対 1e-12 の余裕 |
| 11 | `index_of` の docstring が実装と違う | 採用(docstring) | 「代表と完全一致のみ。等価は `canonical_hkl` で写す」に |
| 12 | #2 と同じ(GLM #2) | 採用 | 同上 |
| 13 | `InterpolatedBackground` の既定 x_min / x_max が固定点と同期しない | 採用 | 既定を NaN にして、省略なら固定点の両端 |
| 参考 | `examples/mem_pbso4.py` の docstring が「z = 1/4」で実際は y 軸 | 採用 | 「y = 1/4(Pnma で Pb と S が乗る鏡面)」と出力名 `pbso4_mem_y025.csv` に直した |

# 検証記録: 自動解析(標準手順の一発)と著者の手動解析の比較(COD の pdCIF)

- 日付: 2026-10-15(kaisetsu 0.1.8 開発版)
- きっかけ: 「XRD + CIF のセットがあるデータベースを探して、自動解析と手動解析を比較。大きく Rwp が
  異なる理由があればそれを見つける」。目的は初心者が自分で測ったデータ(条件は分かっている)の
  解析なので、公開データ特有の事例(変調構造、TOF の pdCIF、有機の拘束付き精密化)は対象外とする。
- データ: Crystallography Open Database(COD)で「powder」を含む 3630 件を HEAD の Content-Length で篩い
  (粉末データ本体が入った CIF は 60 KB 超)、粉末データ本体・精密化済み構造・公表 R 因子の揃った
  pdCIF 101 件(Acta Cryst. B/C/E、Powder Diffraction、J. Phys. Chem.、Cryst. Growth Des. ほか)。
  うち有機(C と H を含む分子性)67 件、無機 34 件。無機は全部、有機は 17 件を処理した時点で止めた。
- 比較の軸: CIF に入っている著者の計算パターン(`_pd_calc_intensity_total` / `_net`)を、同じデータ・
  同じ重み(`_pd_proc_ls_weight`)・同じ式(kaisetsu の Rwp)で評価した値(「著者」)。公表 Rwp は
  定義(背景差引、重み、範囲)がソフトごとに違うので参考にとどめる。Ba(ClO4)2(2240592)で公表 6.00% を
  6.003% と再現し、GSAS の式と一致することを確認した。JANA や TOPAS の pdCIF は重みの列が 1/σ² でない
  ことがある(2019203 は √y に近い)が、同じ重みで両者を評価するので比較は成り立つ。
- 自動解析の条件: CIF の `_diffrn_radiation_type` / `_diffrn_radiation_probe` / 波長 / 試料マウントから
  装置を決め(利用者が装置設定で入れる情報に相当)、幅はプリセット(実験室 X 線 U 0.004 V −0.003
  W 0.004 X 0.02 Y 0.02、放射光は 1/8、中性子は U 0.3 V −0.5 W 0.4)、偏光は CIF にモノクロメータの
  記述があるときだけモノクロの値、背景 Chebyshev 12 項、標準手順の既定(格子定数の初期値走査、
  Kα2 なし・ハンプの試行、軽原子 U 共通化、座標と U)。点数は先頭 15,000 点に制限(著者の計算パターンも
  同じ範囲で評価)。分子性の相(C と H を含み独立サイト 13 以上)は座標を動かさない。
  Le Bail は自動解析の解から構造を外して精密化した下限。
- スクリプト(セッション一時領域): `cod_head_sweep.py`(篩い分け)、`cod_fetch_pdcif.py`(索引)、
  `cod_auto_vs_manual.py`(一括)、`avm_probe.py` / `avm_model.py` / `avm_weights.py`(原因の切り分け)

## 2. 差の原因(無機、条件が分かっている前提で残るもの)

1. **第二相が構造に無い**(2019203、+2.9): 著者の計算パターンには合成の副生成物 LiCl が入っているが、
   CIF の構造は主相だけ。図で見ると 30.1°、34.9°、50.1°、62.5°(LiCl の 111、200、220、222)が自動の
   計算に無い。幅・背景の項数(36 項まで)・キャピラリ吸収(組成から μR = 2.8、CIF 記載 3.0 と一致)・
   試料位置ずれはいずれも効かなかった(3.37〜3.39%)。自動解析の「残差の点検」は 50.1° ほかを
   「相の反射で説明できないピーク」として知らせていた。第二相の自動同定はしない(一覧を出して他の
   プログラムで探す。要検討)。
2. **軽原子の U_iso が個別に決まらない**(2311093、著者 4.29 / 自動 3.44 だが O 4 サイトの U が負):
   軽原子の割合 31.5% が共通化の閾値 30% をわずかに超えて個別に動かした。著者は O 7 サイトを 1 つに
   拘束。→ 閾値に加えて「個別に動かして負か下限に張り付いたら共通化してやり直す」を「変位パラメータ」
   の後処理に入れた(`_retie_negative_light_uiso`)。共通化した U は 0 より下に行かせない(2311093 では
   共通の U が −0.009 に行ったので)。後処理ありで Rwp 3.46%、O の共通 U は 0(下限、著者 0.003)。
   Rwp は個別のとき(3.44%)とほぼ同じで、構造だけが健全になる。
3. **反射ごとに幅が違う(異方的広がり)・選択配向**(7243652 +2.6、2240592 +1.0、2242869 +2.1、
   3000125 +1.2): 図で見ると 7243652 は鋭い反射の高さが自動で半分(同じ幅で全反射を表すため)。
   著者は hkl 依存の幅や March-Dollase を入れている。試料の性質で利用者も知らないことが多いが、
   パラメータが増えるので自動では入れず、「残差の点検」の「強度の不一致」から相の設定で入れる
   (`getting-started.md` 7a 節)。
4. **偏光(モノクロメータ)の仮定**(2242532、自動が 2 ポイント良いが U が全部負): 条件が分かっていれば
   装置設定のプリセットで決まる(モノクロメータ / Ni フィルタ)。無偏光で解くと高角の計算強度が小さく、
   U が負になって補う。著者は U を固定して回避していた。自動の試行はせず、負の U の「注意」に偏光を
   疑う文を残す。
5. **変調構造**(2310780〜84): 著者は hklm の 4 指数で超空間群。対象外。

## 3. 有機(分子性)

座標を動かさない設定でも著者より 2〜12 ポイント悪いものが多い。著者は拘束(2228277 は 57 本)や剛体で
分子の形を保ちながら座標を動かし、Stephens の異方的広がりも使う。自動解析は「同定・定量・格子定数
まで」と割り切る(2228277 に Stephens を足すと 11.0 → 9.9%、選択配向は変化なし、著者 5.6%)。

## 4. 自動解析に反映したもの

- 軽原子 U_iso の共通化を後処理でも行う(上記 2)。
- X 線の散乱因子で重水素 D(と T)を H として扱う(中性子用の CIF を X 線で読んでも落ちない)。
- 標準手順の `Step.after`(段階の後の点検とやり直し)の仕組み。

反映しなかったもの: 第二相の自動同定、選択配向・Stephens の自動試行(過剰パラメータ)、偏光の自動試行
(条件は利用者が知っている)、TOF の pdCIF、巨大セルの速度。

- 日付: 2026-10-11
- 比較対象: diffpy.pdffit2 1.6.0(PyPI、BSD。検証専用の一時 venv に導入。kaisetsu の依存ではない)
- 参照値生成: `uv run python validation/pdffit2/run_pdffit2.py` → `validation/reference/pdffit2_ni.json`
- テスト: `tests/validation/test_pdffit2.py`(`-m validation`、精密化は `slow`)

## 1. 固定パラメータでの G(r)

Ni(Fm-3m、a = 3.524 Å、U_iso = 0.005 Å²、δ2 = 2.0 Å²)、r = 0.01〜20 Å。

| 条件 | max \|ΔG\| | rms ΔG | 備考 |
|---|---|---|---|
| Q_max = 0(終端効果なし)、Q_damp = 0 / 0.06 | 1.0 × 10⁻⁴ | 1 × 10⁻⁵ | ガウス和・規格化・基線・Q_damp は数値精度で一致 |
| Q_max = 40, Q_damp = 0.06(X 線) | 0.054 | 0.019 | ピーク高さ 20.5 の 0.1%。差は r ≈ 20(計算範囲の端)と r < 1 Å に集中 |
| Q_max = 27, Q_damp = 0.02(中性子) | 0.084 | 0.020 | 同上 |

終端効果(有限 Q_max)の表し方が違う: kaisetsu は細かい r グリッド上の G(r) を奇関数として
Q 空間で帯域制限する(diffpy.srreal と同じ考え方)。pdffit2 は計算範囲を少し延ばして
sinc 関数と畳み込む。奇関数/偶関数/ゼロ埋めの拡張、直接畳み込みの範囲を変えて試したが、
どの方式でも rms 0.008〜0.02 の差が残り、pdffit2 と桁で一致する方式は無かった。
データの σ(G)(Ni の X 線で 0.05〜0.7)より小さいので、フィット結果には影響しない(次節)。

## 3. 実装上の注意

- 散乱長: X 線は f(Q = 0)(電子数、イオンならその電子数)、中性子は Sears の b_c 実部。
  pdffit2 と同じ。単元素では規格化で消える。
- 異方性 U_ij は直交座標に直して対方向に射影する(σ'² = e^T (U_i + U_j) e)。
  等方な U_ij を与えると U_iso と同じ G(r) になることをテストで確認。
- 原子対リストは構造(格子・座標・占有率・U)が変わらない限り使い回す。
  スケール・Q_damp・δ だけを動かす段階では原子対の列挙を省ける。
- Q_min(低 Q 側の打ち切り)も帯域制限で扱えるが、既定は 0。

# Phase 6 検証記録: MEM(最大エントロピー法)と MPF

- 日付: 2026-10-11
- 実装: `kaisetsu.mem`(core: 反射の展開・FFT による F_calc・L-BFGS と ZSPA、io: CCP4/XPLOR/grd、
  mpf: Rietveld 分配からの F_obs と σ、MPF)。Pawley 法(`kaisetsu.refine.pawley`)は MEM 入力用の σ 付き強度抽出。
- テスト: `tests/unit/test_mem.py`(合成 F)、`tests/integration/test_mem_pbso4.py`(実データ、slow)、
  `tests/unit/test_pawley.py`
- 外部ソフトとの数値比較は未実施(Dysnomia の例題データが手元に無い)。以下は合成データでの正しさの確認と実データでの妥当性。

## 1. 定式化の確認(合成 F)

| 項目 | 内容 | 結果 |
|---|---|---|
| 反射の展開 | NaCl(Fm-3m)の独立反射を 192 操作 + Friedel で展開し、F(hR) = F(h) exp(−2πi h·t) の位相変換を構造因子の直接計算と比較 | 1e-6 で一致、展開数 = 多重度 |
| NaCl、d ≥ 0.6 Å、32³、|F| に 1% ノイズ | C → 1.00、密度 ≥ 0、等価位置で密度が一致(1e-6)、極大は Na と Cl の位置 | Cl 球(1.4 Å)内 16.1 e(18)、Na 球(1.2 Å)内 9.6 e(10)、総電子数 112.0(= 4 × 28)、R_F 1.2% |
| ZSPA(Sakata-Sato、事前分布 = 前の反復)と L-BFGS | 同じ C で密度の相関 0.99、極大の位置は一致。ZSPA の方がピークが 1〜3 割鋭い(事前分布の逐次更新の効果) | |
| 2 チャンネル(ルチル TiO2、中性子、Ti の b < 0) | d = m⁺ − m⁻ を変数にした正負エントロピーで C → 1。Ti 位置で負、O 位置で正の核密度、総和 = F000 | 16³ で 5 秒 |

MEM の積分電子数が原子の電子数より 1 割ほど少ないのは、分解能(d_min)と MEM の平滑化で密度の裾が広がるためで、
球の半径を大きくすると近づく(Cl: 1.2 Å で 15.2、1.4 Å で 16.1)。

## 2. 解法の速度

| 格子 | 変数 | 内側反復(合計) | 時間 |
|---|---|---|---|
| NaCl 32³(反射 60 本) | m に下限付き L-BFGS-B | 5000 でも未収束 | 56 s / λ |
| 同 | v = 2√m(制約なし) | 1523 で収束 | 12 s / λ |
| 同、λ の割線法探索込み | v = 2√m、目標から遠い λ は 1/5 の反復で打ち切り | 外側 6 回 | 15 s 合計 |

v = 2√m を既定にした(エントロピーの 2 階微分が (1/2) ln(m/τ) + 1 で、m の 1/m より条件数が良い)。

## 3. 実データ: PbSO4(実験室 X 線、`examples/mem_pbso4.py`)

Rietveld(標準の手順 + 試料変位): Rwp = 9.62%、χ² = 3.80。
MEM: 格子 64 × 40 × 54(約 0.13 Å)、反射 270 本程度、σ は Rietveld 分配の誤差伝播(下限 1%)。C = 1.0 に収束。

| 位置 | 密度 [e/Å³] | 球(0.8 Å)内の電子数 |
|---|---|---|
| Pb (4c) | 695 | 68.6(Pb²⁺ 78 e) |
| S | 184 | 11.9 |
| O1 / O2 / O3 | 33 / 39 / 43 | 6.6 / 5.8 / 6.4 |

密度の極大は上位 4 つが Pb の等価位置、5 番目が S。化学的に妥当な分布が得られる。

MPF(|F_MEM|² を固定した表でスケール・背景・格子を再フィット → 再分配 → 再 MEM、2 サイクル):
Rwp 9.62% → 9.44% → 9.54%。1 サイクル目で Rietveld 単独より改善し、2 サイクル目は同程度(収束)。
受け入れ基準(合成データで原子位置に極大、C → 1、実データで妥当な密度、MPF で Rwp 改善)を満たす。

## 4. 注意・残課題

- σ(|F|) は Rietveld 分配の誤差伝播で、重なった反射の分配の不確かさは含まない。Pawley 法の σ(相関込み)も選べる。
- 重なり反射の G 拘束(Dysnomia と同じく群の強度和だけを拘束): `MEMInput.overlap_groups`、
  `mem_from_project(..., group_overlaps=True)` で位置の差が FWHM の半分以内の反射を自動で群にする。
  合成 NaCl で勾配の数値検証と、群の和の再現(5% 以内)・群なしとの密度相関 0.99 を確認。
- Dysnomia / ENIGMA との数値比較は例題データが入手でき次第行う。
- 格子点数は各軸で 2 max|h| + 1 以上が必要(エイリアシング防止)。GUI は格子点間隔 0.1 Å から自動で決める。
